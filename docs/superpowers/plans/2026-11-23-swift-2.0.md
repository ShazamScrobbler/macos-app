# ShazamScrobbler 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Objective-C 1.x menu bar app with a Swift 2.0 that scrobbles Shazam for Mac tags to any number of Last.fm-style and ListenBrainz-style accounts, survives macOS 27's Shazam data protection through a guided Full Disk Access setup, and fixes every previously reported issue.

**Architecture:** A dependency-free Swift package (`Kit/`) holds all logic as testable units: a read-only Shazam reader, a pure scrobbling engine, an SQLite state store, a delivery worker, and two protocol clients. A thin AppKit/SwiftUI app (`App/`, generated with XcodeGen) wires them to a live-updating `NSMenu`, a SwiftUI Settings window and a Full Disk Access setup window. Sparkle 2 is the only runtime dependency (app target only).

**Tech Stack:** Swift 6.4 (Swift 6 language mode), Xcode 27, Swift Package Manager, Swift Testing, SQLite3 (system), URLSession, CryptoKit, Network, AppKit + SwiftUI, ServiceManagement, UserNotifications, Sparkle 2, XcodeGen, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-23-swift-2.0-design.md` — read it before starting any task; section numbers below (§n) refer to it.

## Global Constraints

- Deployment target: `MACOSX_DEPLOYMENT_TARGET = 12.0` (macOS 12 Monterey); universal `arm64` + `x86_64` for Release.
- Swift 6 language mode, `SWIFT_STRICT_CONCURRENCY = complete`; no warnings-as-errors exemptions.
- `Kit/` has **zero** third-party dependencies. The app target's only third-party dependency is **Sparkle 2** (`from: "2.6.0"`).
- App Sandbox **off**; Hardened Runtime **on**.
- Bundle identifier stays **`ShazamScrobbler`** (1.x value; keeps the defaults domain). Keychain service = `ShazamScrobbler`.
- Shazam database: `~/Library/Group Containers/4GWDBCF5A4.group.com.shazam/com.shazam.mac.Shazam/ShazamDataModel.sqlite`, opened **read-only** (`SQLITE_OPEN_READONLY`) only. Only files under `Kit/Sources/ShazamLibrary/` may mention this path; that module must not import or use any networking API.
- App state database: `~/Library/Application Support/ShazamScrobbler/state.sqlite`.
- Secrets (session keys, tokens, own API key/secret) only in the Keychain. Never in `UserDefaults`, never logged.
- Timing: min play time default **45 s** (setting 30–240 s); now playing resent every **240 s**, capped **600 s** after the tag; duplicate (Auto-Shazam) window **600 s**.
- Delivery: Audioscrobbler batch ≤ **50**, ListenBrainz batch ≤ **100**; retry backoff **1, 2, 4 … 60 min ±20 %**; Audioscrobbler rejects tags older than **14 days** (ignored locally).
- Never enumerate login items or mounted volumes (1.x's login-item code triggered a network-volume prompt).
- Logging: `os.Logger(subsystem: "ShazamScrobbler", category: …)` with categories `shazam`, `engine`, `delivery`, `lastfm`, `listenbrainz`, `ui`. Never log secrets.
- User-visible strings in the app go through `String(localized:)` and `App/Resources/Localizable.xcstrings`.
- Release signing: one stable self-signed certificate "ShazamScrobbler Signing"; designated requirement must be `identifier "ShazamScrobbler" and certificate leaf = H"<sha1>"` (never ad-hoc for releases — FDA would be lost on every update, verified in §6.5).
- 1.x code (`ShazamScrobbler/`, `Pods/`, `Podfile*`, `*.xcworkspace`, the old `ShazamScrobbler.xcodeproj`) stays untouched until Task 24. The owner has uncommitted local changes in `Pods/`, `Podfile` and `ShazamScrobbler.xcodeproj/project.pbxproj`; never stage them (always `git add` explicit paths).

## Review Focus

1. **Our own refreshed "now playing" mistaken for another player:** after 2.0 sends now playing for song A, Last.fm's recent tracks show A as "now playing"; when song B is tagged, the other-player check must ignore A or every song after the first is skipped. Tests: Task 8 (`isOtherPlayerActive(excluding:)`), Task 11 (Delivery passes the last track it sent).
2. **Shazam rows with no album, several artists, or no artist:** a tag without an `Album` metadata row must still scrobble (1.x's inner join dropped it); several artist rows → first artist, one scrobble; no artist → not scrobblable, skipped without crashing. Tests: Task 3.
3. **Auto-Shazam re-tags of the same song:** a duplicate re-tag 30 s after the original must not mark the original "not played long enough" and must not scrobble twice. Tests: Task 4.
4. **Quit or crash during the 45 s window:** after relaunch, a tag persisted as `nowPlaying` with a past deadline and no newer tag must be scrobbled exactly once; with a newer tag it must become `tooShort`. Tests: Task 4 and Task 12 (restart with the same state file).
5. **Last.fm JSON quirks:** one-item batches and one-item recent-tracks lists come back as an object instead of an array, and errors can arrive with HTTP 200 or 4xx bodies; all must parse. Tests: Task 8.

**Deliberate narrowings of the spec** (keep, unless the owner asks otherwise): the Accounts list shows each account's health, not a per-account waiting count (the menu shows the total waiting); 1.x's login-item entry is left in place rather than migrated (it opens the same app path, and removing it would require enumerating login items).

`Kit/Sources/SQLiteLite/SQLiteDatabase.swift`:
```swift
import Foundation
import SQLite3

public enum SQLiteValue: Equatable, Sendable {
    case null
    case integer(Int64)
    case real(Double)
    case text(String)
}

public struct SQLiteError: Error, Equatable, Sendable, CustomStringConvertible {
    public let code: Int32
    public let extendedCode: Int32
    public let systemErrno: Int32
    public let message: String

    /// macOS privacy refusals surface as EPERM from open(2); plain file permissions as EACCES.
    public var isPermissionDenied: Bool {
        code == SQLITE_AUTH || code == SQLITE_PERM || systemErrno == EPERM || systemErrno == EACCES
    }
    public var isBusy: Bool { code == SQLITE_BUSY || code == SQLITE_LOCKED }
    public var description: String { "SQLite \(code)/\(extendedCode) errno=\(systemErrno): \(message)" }
}

public struct SQLiteRow: Sendable {
    let values: [String: SQLiteValue]
    public subscript(_ column: String) -> SQLiteValue { values[column] ?? .null }
    public func string(_ column: String) -> String? {
        if case let .text(s) = self[column] { return s }
        return nil
    }
    public func int(_ column: String) -> Int64? {
        switch self[column] {
        case let .integer(i): return i
        case let .real(d): return Int64(d)
        default: return nil
        }
    }
    public func double(_ column: String) -> Double? {
        switch self[column] {
        case let .real(d): return d
        case let .integer(i): return Double(i)
        default: return nil
        }
    }
}

/// One connection. Calls are serialized with a lock; callers own higher-level concurrency.
public final class SQLiteDatabase: @unchecked Sendable {
    public enum Mode: Sendable { case readOnly, readWriteCreate, inMemory }

    private let handle: OpaquePointer?
    private let lock = NSLock()

    public init(path: String, mode: Mode, busyTimeoutMs: Int32 = 2000) throws {
        let flags: Int32 = mode == .readOnly
            ? SQLITE_OPEN_READONLY | SQLITE_OPEN_NOMUTEX
            : SQLITE_OPEN_READWRITE | SQLITE_OPEN_CREATE | SQLITE_OPEN_NOMUTEX
        var db: OpaquePointer?
        let rc = sqlite3_open_v2(mode == .inMemory ? ":memory:" : path, &db, flags, nil)
        guard rc == SQLITE_OK else {
            let error = Self.error(db, rc)
            sqlite3_close_v2(db)
            throw error
        }
        sqlite3_extended_result_codes(db, 1)
        sqlite3_busy_timeout(db, busyTimeoutMs)
        handle = db
    }

    deinit { sqlite3_close_v2(handle) }

    public func execute(_ sql: String) throws {
        lock.lock(); defer { lock.unlock() }
        let rc = sqlite3_exec(handle, sql, nil, nil, nil)
        guard rc == SQLITE_OK else { throw Self.error(handle, rc) }
    }

    @discardableResult
    public func query(_ sql: String, _ bindings: [SQLiteValue] = []) throws -> [SQLiteRow] {
        lock.lock(); defer { lock.unlock() }
        var stmt: OpaquePointer?
        var rc = sqlite3_prepare_v2(handle, sql, -1, &stmt, nil)
        guard rc == SQLITE_OK else { throw Self.error(handle, rc) }
        defer { sqlite3_finalize(stmt) }
        for (offset, value) in bindings.enumerated() {
            let index = Int32(offset + 1)
            switch value {
            case .null: rc = sqlite3_bind_null(stmt, index)
            case let .integer(n): rc = sqlite3_bind_int64(stmt, index, n)
            case let .real(d): rc = sqlite3_bind_double(stmt, index, d)
            case let .text(s): rc = sqlite3_bind_text(stmt, index, s, -1, sqliteTransient)
            }
            guard rc == SQLITE_OK else { throw Self.error(handle, rc) }
        }
        var rows: [SQLiteRow] = []
        while true {
            rc = sqlite3_step(stmt)
            if rc == SQLITE_DONE { break }
            guard rc == SQLITE_ROW else { throw Self.error(handle, rc) }
            var values: [String: SQLiteValue] = [:]
            for column in 0..<sqlite3_column_count(stmt) {
                let name = String(cString: sqlite3_column_name(stmt, column))
                switch sqlite3_column_type(stmt, column) {
                case SQLITE_INTEGER: values[name] = .integer(sqlite3_column_int64(stmt, column))
                case SQLITE_FLOAT: values[name] = .real(sqlite3_column_double(stmt, column))
                case SQLITE_TEXT: values[name] = .text(String(cString: sqlite3_column_text(stmt, column)))
                default: values[name] = .null
                }
            }
            rows.append(SQLiteRow(values: values))
        }
        return rows
    }

    public func transaction<T>(_ body: () throws -> T) throws -> T {
        try execute("BEGIN IMMEDIATE")
        do {
            let result = try body()
            try execute("COMMIT")
            return result
        } catch {
            try? execute("ROLLBACK")
            throw error
        }
    }

    static func error(_ db: OpaquePointer?, _ rc: Int32) -> SQLiteError {
        SQLiteError(
            code: rc & 0xFF,
            extendedCode: db.map { sqlite3_extended_errcode($0) } ?? rc,
            systemErrno: db.map { sqlite3_system_errno($0) } ?? 0,
            message: db.map { String(cString: sqlite3_errmsg($0)) } ?? String(cString: sqlite3_errstr(rc))
        )
    }
}

private let sqliteTransient = unsafeBitCast(-1, to: sqlite3_destructor_type.self)
```

import Foundation
import os
import ScrobbleCore
import SQLiteLite

/// The only code allowed to touch Shazam's container (see scripts/check-boundaries.sh).
/// Opens the database read-only; never writes, never uses the network.
public struct ShazamLibrary: TagSource {
    public static let defaultContainerURL = URL(fileURLWithPath: NSHomeDirectory())
        .appendingPathComponent("Library/Group Containers/4GWDBCF5A4.group.com.shazam")
    public static let defaultShazamAppURL = URL(fileURLWithPath: "/Applications/Shazam.app")

    public let containerURL: URL
    public let shazamAppURL: URL
    public var watchedDirectoryURL: URL { containerURL.appendingPathComponent("com.shazam.mac.Shazam") }
    public var databaseURL: URL { watchedDirectoryURL.appendingPathComponent("ShazamDataModel.sqlite") }

    private static let log = Logger(subsystem: "ShazamScrobbler", category: "shazam")
    private static let requiredColumns: [(table: String, columns: [String])] = [
        ("ZSHTAGRESULTMO", ["Z_PK", "ZDATE", "ZTRACKNAME"]),
        ("ZSHARTISTMO", ["Z_PK", "ZTAGRESULT", "ZNAME"]),
        ("ZSHMETADATAMO", ["Z_PK", "ZTAGRESULT", "ZKEY", "ZVALUE"]),
    ]

    public init(containerURL: URL = ShazamLibrary.defaultContainerURL,
                shazamAppURL: URL = ShazamLibrary.defaultShazamAppURL) {
        self.containerURL = containerURL
        self.shazamAppURL = shazamAppURL
    }

    public func read(since: Date, recentLimit: Int) -> TagSourceResult {
        let fm = FileManager.default
        guard fm.fileExists(atPath: containerURL.path) else {
            return TagSourceResult(status: fm.fileExists(atPath: shazamAppURL.path) ? .noLibraryYet : .notInstalled)
        }
        do {
            let db = try SQLiteDatabase(path: databaseURL.path, mode: .readOnly)
            if let missing = try Self.schemaProblem(db) {
                Self.log.error("Unsupported Shazam schema, missing \(missing, privacy: .public)")
                return TagSourceResult(status: .unsupportedSchema(missing))
            }
            let recent = try Self.tags(db, filter: "1=1", bindings: [], ascending: false, limit: recentLimit)
            guard !recent.isEmpty else { return TagSourceResult(status: .noLibraryYet) }
            let since = try Self.tags(db, filter: "t.ZDATE > ?", bindings: [.real(since.timeIntervalSinceReferenceDate)],
                                      ascending: true, limit: nil)
            return TagSourceResult(status: .ok, tagsSince: since, recent: recent)
        } catch let error as SQLiteError {
            return TagSourceResult(status: classify(error))
        } catch {
            return TagSourceResult(status: .unreadable(String(describing: error)))
        }
    }

    public func tags(withPKs pks: [Int64]) -> [Int64: ShazamTag] {
        guard !pks.isEmpty, let db = try? SQLiteDatabase(path: databaseURL.path, mode: .readOnly) else { return [:] }
        let placeholders = Array(repeating: "?", count: pks.count).joined(separator: ",")
        let found = (try? Self.tags(db, filter: "t.Z_PK IN (\(placeholders))", bindings: pks.map { .integer($0) },
                                    ascending: true, limit: nil)) ?? []
        return Dictionary(found.map { ($0.pk, $0) }, uniquingKeysWith: { a, _ in a })
    }

    private func classify(_ error: SQLiteError) -> LibraryStatus {
        if error.isPermissionDenied {
            Self.log.notice("Shazam database read refused: \(error.description, privacy: .public)")
            return .accessDenied
        }
        if !FileManager.default.fileExists(atPath: databaseURL.path) { return .noLibraryYet }
        Self.log.error("Shazam database unreadable: \(error.description, privacy: .public)")
        return .unreadable(error.description)
    }

    private static func schemaProblem(_ db: SQLiteDatabase) throws -> String? {
        for (table, columns) in requiredColumns {
            let present = Set(try db.query("PRAGMA table_info(\(table))").compactMap { $0.string("name") })
            if present.isEmpty { return table }
            if let missing = columns.first(where: { !present.contains($0) }) { return "\(table).\(missing)" }
        }
        return nil
    }

    private static func tags(_ db: SQLiteDatabase, filter: String, bindings: [SQLiteValue],
                             ascending: Bool, limit: Int?) throws -> [ShazamTag] {
        let order = ascending ? "ASC" : "DESC"
        let sql = """
            SELECT t.Z_PK AS pk, t.ZDATE AS date, t.ZTRACKNAME AS title,
              (SELECT a.ZNAME FROM ZSHARTISTMO a WHERE a.ZTAGRESULT = t.Z_PK ORDER BY a.Z_PK LIMIT 1) AS artist,
              (SELECT m.ZVALUE FROM ZSHMETADATAMO m WHERE m.ZTAGRESULT = t.Z_PK AND m.ZKEY = 'Album'
                 ORDER BY m.Z_PK LIMIT 1) AS album
            FROM ZSHTAGRESULTMO t
            WHERE \(filter) AND t.ZTRACKNAME IS NOT NULL AND t.ZTRACKNAME <> ''
              AND EXISTS (SELECT 1 FROM ZSHARTISTMO a WHERE a.ZTAGRESULT = t.Z_PK AND a.ZNAME <> '')
            ORDER BY t.ZDATE \(order), t.Z_PK \(order)
            \(limit.map { "LIMIT \($0)" } ?? "")
            """
        return try db.query(sql, bindings).compactMap { row in
            guard let pk = row.int("pk"), let seconds = row.double("date"),
                  let title = row.string("title"), let artist = row.string("artist") else { return nil }
            let album = row.string("album").flatMap { $0.isEmpty ? nil : $0 }
            return ShazamTag(pk: pk, date: Date(timeIntervalSinceReferenceDate: seconds),
                             track: Track(artist: artist, title: title, album: album))
        }
    }
}

/// Pure scrobbling rules (spec §5). No I/O, no clock: everything comes in through `EngineInput`.
public enum ScrobbleEngine {
    public static func evaluate(_ input: EngineInput) -> EngineOutput {
        let settings = input.settings
        let sorted = input.tags.sorted { ($0.date, $0.pk) < ($1.date, $1.pk) }

        var seenKeys = Set<TagKey>()
        let unique = sorted.filter { seenKeys.insert($0.key).inserted }

        var lastSeenBySong: [String: Date] = [:]
        var duplicates = Set<TagKey>()
        for tag in unique {
            let song = tag.track.matchKey
            if let previous = lastSeenBySong[song],
               tag.date.timeIntervalSince(previous) < EngineSettings.duplicateWindow {
                duplicates.insert(tag.key)
            }
            lastSeenBySong[song] = tag.date
        }

        let plays = unique.filter { !duplicates.contains($0.key) }
        var following: [TagKey: ShazamTag] = [:]
        for (index, tag) in plays.enumerated() where index + 1 < plays.count {
            following[tag.key] = plays[index + 1]
        }

        var transitions: [Transition] = []
        var resulting: [TagKey: [AccountID: DeliveryState]] = input.states
        var earliestWake: Date?
        func wake(at date: Date) {
            guard date > input.now else { return }
            earliestWake = min(earliestWake ?? date, date)
        }

        for tag in unique {
            for account in input.accounts where tag.date > account.since {
                let current = input.states[tag.key]?[account.id]
                let next = nextState(for: tag, current: current, isDuplicate: duplicates.contains(tag.key),
                                     following: following[tag.key], input: input)
                guard let next else { continue }
                if next != current {
                    transitions.append(Transition(key: tag.key, tag: tag, account: account.id, to: next))
                    resulting[tag.key, default: [:]][account.id] = next
                }
                if case let .nowPlaying(deadline) = next { wake(at: deadline) }
            }
        }

        var requests: [NowPlayingRequest] = []
        if let newest = plays.last, !settings.paused,
           input.now.timeIntervalSince(newest.date) < EngineSettings.nowPlayingCap {
            for account in input.accounts where newest.date > account.since {
                guard let state = resulting[newest.key]?[account.id], allowsNowPlaying(state) else { continue }
                let last = input.lastNowPlaying[account.id]
                if last?.key == newest.key, let sentAt = last?.sentAt {
                    let due = sentAt + EngineSettings.nowPlayingResendInterval
                    if input.now >= due {
                        requests.append(NowPlayingRequest(account: account.id, tag: newest, isRefresh: true))
                        scheduleRefresh(from: input.now, tag: newest, wake: wake(at:))
                    } else {
                        scheduleRefresh(from: sentAt, tag: newest, wake: wake(at:))
                    }
                } else if case .nowPlaying = state {
                    requests.append(NowPlayingRequest(account: account.id, tag: newest, isRefresh: false))
                    scheduleRefresh(from: input.now, tag: newest, wake: wake(at:))
                }
            }
        }

        return EngineOutput(transitions: transitions, nowPlaying: requests, nextWake: earliestWake)
    }

    private static func scheduleRefresh(from sentAt: Date, tag: ShazamTag, wake: (Date) -> Void) {
        let next = sentAt + EngineSettings.nowPlayingResendInterval
        if next.timeIntervalSince(tag.date) < EngineSettings.nowPlayingCap { wake(next) }
    }

    private static func allowsNowPlaying(_ state: DeliveryState) -> Bool {
        switch state {
        case .nowPlaying, .waiting, .retry, .scrobbled: true
        case .tooShort, .skipped, .ignored, .held: false
        }
    }

    private static func nextState(for tag: ShazamTag, current: DeliveryState?, isDuplicate: Bool,
                                  following: ShazamTag?, input: EngineInput) -> DeliveryState? {
        if input.excluded.contains(tag.key) {
            switch current {
            case .scrobbled?, .ignored?, .skipped(.user)?: return current
            default: return .skipped(.user)
            }
        }
        switch current {
        case nil:
            if isDuplicate { return .skipped(.duplicate) }
            if input.settings.paused && input.settings.pauseMode == .ignore { return .skipped(.paused) }
            return playState(for: tag, following: following, input: input)
        case .nowPlaying?:
            return playState(for: tag, following: following, input: input)
        case .skipped(.user)?:
            return .waiting   // no longer excluded: the user chose "Scrobble Anyway"
        case .tooShort?, .skipped?:
            return input.forced.contains(tag.key) ? .waiting : current
        default:
            return current
        }
    }

    private static func playState(for tag: ShazamTag, following: ShazamTag?, input: EngineInput) -> DeliveryState {
        if let next = following {
            return next.date.timeIntervalSince(tag.date) < input.settings.minPlayTime ? .tooShort : .waiting
        }
        let deadline = tag.date + input.settings.minPlayTime
        return input.now < deadline ? .nowPlaying(deadline: deadline) : .waiting
    }
}

import Foundation
import SQLiteLite

public struct PendingItem: Sendable, Equatable {
    public var key: TagKey
    public var track: Track
    public var date: Date
    public var state: DeliveryState
}

public enum UserChoice: String, Sendable {
    case exclude
    case force
}

/// The app's own database (spec §4). Replaces 1.x `lastScrobble` / `notToScrobble`.
public final class StateStore: @unchecked Sendable {
    public static var defaultURL: URL {
        FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask)[0]
            .appendingPathComponent("ShazamScrobbler/state.sqlite")
    }

    private let db: SQLiteDatabase

    public init(url: URL?) throws {
        if let url {
            try FileManager.default.createDirectory(at: url.deletingLastPathComponent(), withIntermediateDirectories: true)
            db = try SQLiteDatabase(path: url.path, mode: .readWriteCreate)
            try db.execute("PRAGMA journal_mode=WAL")
        } else {
            db = try SQLiteDatabase(path: "", mode: .inMemory)
        }
        try migrate()
    }

    private func migrate() throws {
        try db.execute("CREATE TABLE IF NOT EXISTS meta(key TEXT PRIMARY KEY, value TEXT NOT NULL)")
        let version = try meta("schema_version").flatMap(Int.init) ?? 0
        if version < 1 {
            try db.transaction {
                try db.execute("""
                    CREATE TABLE tags(key TEXT PRIMARY KEY, pk INTEGER, date REAL NOT NULL,
                                      artist TEXT NOT NULL, title TEXT NOT NULL, album TEXT);
                    CREATE INDEX tags_date ON tags(date);
                    CREATE TABLE deliveries(tag_key TEXT NOT NULL, account TEXT NOT NULL, kind TEXT NOT NULL,
                                            next_at REAL, state TEXT NOT NULL, updated REAL NOT NULL,
                                            PRIMARY KEY(tag_key, account));
                    CREATE INDEX deliveries_account_kind ON deliveries(account, kind);
                    CREATE TABLE user_choices(tag_key TEXT PRIMARY KEY, choice TEXT NOT NULL);
                    CREATE TABLE cursors(account TEXT PRIMARY KEY, since REAL NOT NULL);
                    CREATE TABLE now_playing(account TEXT PRIMARY KEY, tag_key TEXT NOT NULL, sent_at REAL NOT NULL);
                    """)
                try setMeta("schema_version", "1")
            }
        }
    }

    // MARK: meta

    public func meta(_ key: String) throws -> String? {
        try db.query("SELECT value FROM meta WHERE key = ?", [.text(key)]).first?.string("value")
    }

    public func setMeta(_ key: String, _ value: String?) throws {
        if let value {
            try db.query("INSERT OR REPLACE INTO meta(key, value) VALUES(?, ?)", [.text(key), .text(value)])
        } else {
            try db.query("DELETE FROM meta WHERE key = ?", [.text(key)])
        }
    }

    // MARK: tags and states

    public func record(_ tags: [ShazamTag]) throws {
        guard !tags.isEmpty else { return }
        try db.transaction { for tag in tags { try insert(tag) } }
    }

    private func insert(_ tag: ShazamTag) throws {
        try db.query("INSERT OR IGNORE INTO tags(key, pk, date, artist, title, album) VALUES(?,?,?,?,?,?)", [
            .text(tag.key.rawValue), .integer(tag.pk), .real(tag.date.timeIntervalSince1970),
            .text(tag.track.artist), .text(tag.track.title), tag.track.album.map(SQLiteValue.text) ?? .null,
        ])
    }

    public func apply(_ transitions: [Transition], now: Date) throws {
        guard !transitions.isEmpty else { return }
        try db.transaction {
            for t in transitions {
                try insert(t.tag)
                try write(t.to, key: t.key, account: t.account, now: now)
            }
        }
    }

    public func set(_ state: DeliveryState, key: TagKey, account: AccountID, now: Date) throws {
        try write(state, key: key, account: account, now: now)
    }

    private func write(_ state: DeliveryState, key: TagKey, account: AccountID, now: Date) throws {
        let json = String(decoding: try JSONEncoder().encode(state), as: UTF8.self)
        try db.query("""
            INSERT OR REPLACE INTO deliveries(tag_key, account, kind, next_at, state, updated) VALUES(?,?,?,?,?,?)
            """, [.text(key.rawValue), .text(account.rawValue), .text(state.kind),
                  state.retryAt.map { .real($0.timeIntervalSince1970) } ?? .null, .text(json),
                  .real(now.timeIntervalSince1970)])
    }

    public func states(since: Date) throws -> [TagKey: [AccountID: DeliveryState]] {
        try collect(db.query("""
            SELECT d.tag_key, d.account, d.state FROM deliveries d JOIN tags t ON t.key = d.tag_key WHERE t.date > ?
            """, [.real(since.timeIntervalSince1970)]))
    }

    public func states(for keys: [TagKey]) throws -> [TagKey: [AccountID: DeliveryState]] {
        guard !keys.isEmpty else { return [:] }
        let marks = Array(repeating: "?", count: keys.count).joined(separator: ",")
        return try collect(db.query("SELECT tag_key, account, state FROM deliveries WHERE tag_key IN (\(marks))",
                                    keys.map { .text($0.rawValue) }))
    }

    private func collect(_ rows: [SQLiteRow]) throws -> [TagKey: [AccountID: DeliveryState]] {
        var result: [TagKey: [AccountID: DeliveryState]] = [:]
        let decoder = JSONDecoder()
        for row in rows {
            guard let key = row.string("tag_key"), let account = row.string("account"),
                  let json = row.string("state") else { continue }
            result[TagKey(rawValue: key), default: [:]][AccountID(rawValue: account)] =
                try decoder.decode(DeliveryState.self, from: Data(json.utf8))
        }
        return result
    }

    public func track(for key: TagKey) throws -> Track? {
        try db.query("SELECT artist, title, album FROM tags WHERE key = ?", [.text(key.rawValue)]).first.flatMap { row in
            guard let artist = row.string("artist"), let title = row.string("title") else { return nil }
            return Track(artist: artist, title: title, album: row.string("album"))
        }

    public func pending(account: AccountID, dueBy now: Date, limit: Int) throws -> [PendingItem] {
        let decoder = JSONDecoder()
        return try db.query("""
            SELECT d.tag_key, d.state, t.date, t.artist, t.title, t.album
            FROM deliveries d JOIN tags t ON t.key = d.tag_key
            WHERE d.account = ? AND (d.kind = 'waiting' OR (d.kind = 'retry' AND d.next_at <= ?))
            ORDER BY t.date ASC LIMIT ?
            """, [.text(account.rawValue), .real(now.timeIntervalSince1970), .integer(Int64(limit))]).compactMap { row in
            guard let key = row.string("tag_key"), let json = row.string("state"), let date = row.double("date"),
                  let artist = row.string("artist"), let title = row.string("title") else { return nil }
            return PendingItem(key: TagKey(rawValue: key), track: Track(artist: artist, title: title, album: row.string("album")),
                               date: Date(timeIntervalSince1970: date),
                               state: try decoder.decode(DeliveryState.self, from: Data(json.utf8)))
        }
    }

        try db.query("SELECT MIN(next_at) AS n FROM deliveries WHERE kind = 'retry'").first?.double("n")
            .map(Date.init(timeIntervalSince1970:))
    }

    public func heldProblems() throws -> [AccountID: AccountProblem] {
        var result: [AccountID: AccountProblem] = [:]
        for row in try db.query("SELECT account, state FROM deliveries WHERE kind = 'held' GROUP BY account") {
            guard let account = row.string("account"), let json = row.string("state"),
                  case let .held(problem) = try JSONDecoder().decode(DeliveryState.self, from: Data(json.utf8)) else { continue }
            result[AccountID(rawValue: account)] = problem
        }
        return result

    public func hold(account: AccountID, problem: AccountProblem, now: Date = Date()) throws {
        try rewrite(account: account, kinds: ["waiting", "retry"], to: .held(problem), now: now)
    }

    public func releaseHeld(account: AccountID, now: Date = Date()) throws {
        try rewrite(account: account, kinds: ["held"], to: .waiting, now: now)
    }

    private func rewrite(account: AccountID, kinds: [String], to state: DeliveryState, now: Date) throws {
        let marks = kinds.map { _ in "?" }.joined(separator: ",")
        let json = String(decoding: try JSONEncoder().encode(state), as: UTF8.self)
        try db.query("""
            UPDATE deliveries SET kind = ?, next_at = NULL, state = ?, updated = ? WHERE account = ? AND kind IN (\(marks))
            """, [.text(state.kind), .text(json), .real(now.timeIntervalSince1970), .text(account.rawValue)] + kinds.map { .text($0) })
    }

    public func waitingCount() throws -> Int {
        Int(try db.query("""
            SELECT COUNT(DISTINCT tag_key) AS c FROM deliveries WHERE kind IN ('waiting', 'retry', 'held')
            """).first?.int("c") ?? 0)
    }

    /// "Skip N Waiting" (#28): skips everything not yet sent and remembers it as excluded,
    /// so the engine doesn't revive it.
    @discardableResult
    public func skipAllWaiting(now: Date) throws -> Int {
        try db.transaction {
            let keys = try db.query("""
                SELECT DISTINCT tag_key FROM deliveries WHERE kind IN ('waiting', 'retry', 'held')
                """).compactMap { $0.string("tag_key") }
            let json = String(decoding: try JSONEncoder().encode(DeliveryState.skipped(.user)), as: UTF8.self)
            for key in keys {
                try db.query("""
                    UPDATE deliveries SET kind = 'skipped', next_at = NULL, state = ?, updated = ?
                    WHERE tag_key = ? AND kind IN ('waiting', 'retry', 'held')
                    """, [.text(json), .real(now.timeIntervalSince1970), .text(key)])
                try db.query("INSERT OR REPLACE INTO user_choices(tag_key, choice) VALUES(?, 'exclude')", [.text(key)])
            }
            return keys.count
        }
    }

    // MARK: user choices

    public func setChoice(_ choice: UserChoice?, for key: TagKey) throws {
        if let choice {
            try db.query("INSERT OR REPLACE INTO user_choices(tag_key, choice) VALUES(?, ?)",
                         [.text(key.rawValue), .text(choice.rawValue)])
        } else {
            try db.query("DELETE FROM user_choices WHERE tag_key = ?", [.text(key.rawValue)])
        }
    }

    public func choices() throws -> (excluded: Set<TagKey>, forced: Set<TagKey>) {
        var excluded = Set<TagKey>(), forced = Set<TagKey>()
        for row in try db.query("SELECT tag_key, choice FROM user_choices") {
            guard let key = row.string("tag_key") else { continue }
            if row.string("choice") == UserChoice.exclude.rawValue { excluded.insert(TagKey(rawValue: key)) }
            else { forced.insert(TagKey(rawValue: key)) }
        }
        return (excluded, forced)
    }

    // MARK: cursors

    public func cursor(for account: AccountID) throws -> Date? {
        try db.query("SELECT since FROM cursors WHERE account = ?", [.text(account.rawValue)]).first?.double("since")
            .map(Date.init(timeIntervalSince1970:))
    }

    public func setCursor(_ date: Date, for account: AccountID) throws {
        try db.query("INSERT OR REPLACE INTO cursors(account, since) VALUES(?, ?)",
                     [.text(account.rawValue), .real(date.timeIntervalSince1970)])
    }

    /// Moves the cursor forward to just before the oldest unfinished tag (or to the newest
    /// finished one), so scans don't re-read the whole history. Never moves backwards.
    public func advanceCursor(for account: AccountID) throws {
        let id = SQLiteValue.text(account.rawValue)
        let oldestOpen = try db.query("""
            SELECT MIN(t.date) AS d FROM deliveries d JOIN tags t ON t.key = d.tag_key
            WHERE d.account = ? AND d.kind IN ('waiting', 'nowPlaying', 'retry', 'held')
            """, [id]).first?.double("d")
        let newestAny = try db.query("""
            SELECT MAX(t.date) AS d FROM deliveries d JOIN tags t ON t.key = d.tag_key WHERE d.account = ?
            """, [id]).first?.double("d")
        guard let target = oldestOpen.map({ $0 - 0.001 }) ?? newestAny else { return }
        let current = try cursor(for: account)?.timeIntervalSince1970 ?? -.infinity
        if target > current { try setCursor(Date(timeIntervalSince1970: target), for: account) }
    }

    // MARK: now playing

    public func lastNowPlaying() throws -> [AccountID: NowPlayingRecord] {
        var result: [AccountID: NowPlayingRecord] = [:]
        for row in try db.query("SELECT account, tag_key, sent_at FROM now_playing") {
            guard let account = row.string("account"), let key = row.string("tag_key"),
                  let sentAt = row.double("sent_at") else { continue }
            result[AccountID(rawValue: account)] = NowPlayingRecord(key: TagKey(rawValue: key),
                                                                    sentAt: Date(timeIntervalSince1970: sentAt))
        }
        return result
    }

    public func setNowPlaying(_ record: NowPlayingRecord, for account: AccountID) throws {
        try db.query("INSERT OR REPLACE INTO now_playing(account, tag_key, sent_at) VALUES(?,?,?)",
                     [.text(account.rawValue), .text(record.key.rawValue), .real(record.sentAt.timeIntervalSince1970)])
    }

    public func removeAccount(_ account: AccountID) throws {
        try db.transaction {
            for table in ["deliveries", "cursors", "now_playing"] {
                try db.query("DELETE FROM \(table) WHERE account = ?", [.text(account.rawValue)])
            }
        }
    }
}

extension DeliveryState {
    var kind: String {
        switch self {
        case .waiting: "waiting"
        case .nowPlaying: "nowPlaying"
        case .scrobbled: "scrobbled"
        case .tooShort: "tooShort"
        case .skipped: "skipped"
        case .ignored: "ignored"
        case .held: "held"
        case .retry: "retry"
        }
    }

    var retryAt: Date? {
        if case let .retry(_, nextAt) = self { return nextAt }
        return nil
    }
}

import Foundation

public enum ScrobbleError: Error, Equatable, Sendable {
    case signedOut
    case keyUnusable(code: Int)
    case transient(String)
    case rateLimited(retryAfter: TimeInterval?)
    case permanent(String)
}

extension Error {
    public var asScrobbleError: ScrobbleError {
        (self as? ScrobbleError) ?? .transient(String(describing: self))
    }
}

public enum Backoff {
    /// 1, 2, 4 … minutes, capped at 60, with ±20 % jitter (`random` in 0..<1).
    public static func delay(attempt: Int, random: Double) -> TimeInterval {
        let minutes = min(60.0, pow(2.0, Double(max(attempt, 1) - 1)))
        return minutes * 60 * (0.8 + 0.4 * random)
    }

    public static func nextUTCMidnight(after date: Date) -> Date {
        var calendar = Calendar(identifier: .gregorian)
        calendar.timeZone = TimeZone(identifier: "UTC")!
        return calendar.date(byAdding: .day, value: 1, to: calendar.startOfDay(for: date))!
    }
}

public enum DeliveryPolicy {
    public static func state(after error: ScrobbleError, previous: DeliveryState?, now: Date, random: Double) -> DeliveryState {
        let attempt: Int
        if case let .retry(previousAttempt, _)? = previous { attempt = previousAttempt + 1 } else { attempt = 1 }
        switch error {
        case .signedOut: return .held(.signedOut)
        case .keyUnusable: return .held(.keyUnusable)
        case let .permanent(message): return .ignored(message)
        case .transient: return .retry(attempt: attempt, nextAt: now + Backoff.delay(attempt: attempt, random: random))
        case let .rateLimited(after):
            return .retry(attempt: attempt, nextAt: now + (after ?? Backoff.delay(attempt: attempt, random: random)))
        }
    }

    public static func problem(for error: ScrobbleError) -> AccountProblem? {
        switch error {
        case .signedOut: .signedOut
        case .keyUnusable: .keyUnusable
        default: nil
        }
    }
}

import Foundation

public protocol HTTPTransport: Sendable {
    func send(_ request: URLRequest) async throws -> (Data, HTTPURLResponse)
}

public struct URLSessionTransport: HTTPTransport {
    private let session: URLSession

    public init() {
        let configuration = URLSessionConfiguration.ephemeral
        configuration.timeoutIntervalForRequest = 30
        configuration.httpAdditionalHeaders = ["User-Agent": "ShazamScrobbler/2 (macOS)"]
        session = URLSession(configuration: configuration)
    }

    public func send(_ request: URLRequest) async throws -> (Data, HTTPURLResponse) {
        let (data, response) = try await session.data(for: request)
        guard let http = response as? HTTPURLResponse else { throw URLError(.badServerResponse) }
        return (data, http)
    }
}

public enum FormEncoding {
    private static let allowed: CharacterSet = {
        var set = CharacterSet.alphanumerics
        set.insert(charactersIn: "-._~")
        return set
    }()

    public static func encode(_ params: [String: String]) -> Data {
        Data(params.sorted { $0.key < $1.key }
            .map { "\(escape($0.key))=\(escape($0.value))" }
            .joined(separator: "&").utf8)
    }

    public static func decode(_ data: Data) -> [String: String] {
        var result: [String: String] = [:]
        for pair in String(decoding: data, as: UTF8.self).split(separator: "&") {
            let parts = pair.split(separator: "=", maxSplits: 1).map(String.init)
            guard let name = parts.first?.removingPercentEncoding else { continue }
            result[name] = parts.count > 1 ? parts[1].removingPercentEncoding ?? "" : ""
        }
        return result
    }

    static func escape(_ s: String) -> String {
        s.addingPercentEncoding(withAllowedCharacters: allowed) ?? s
    }
}

import CryptoKit
import Foundation
import ScrobbleCore

public enum AudioscrobblerSignature {
    public static func sign(_ params: [String: String], secret: String) -> String {
        let base = params
            .filter { $0.key != "format" && $0.key != "callback" }
            .sorted { $0.key < $1.key }
            .map { $0.key + $0.value }
            .joined() + secret
        return Insecure.MD5.hash(data: Data(base.utf8)).map { String(format: "%02x", $0) }.joined()
    }
}

/// Shared request/response handling for every Audioscrobbler 2.0 call.
struct AudioscrobblerAPI: Sendable {
    let apiURL: URL
    let apiKey: String
    let apiSecret: String
    let transport: any HTTPTransport

    /// Returns the decoded JSON object or throws `ScrobbleError` (or `AudioscrobblerCallError` for auth codes).
    func call(method: String, params: [String: String], sessionKey: String? = nil,
              signed: Bool = true, get: Bool = false) async throws -> [String: Any] {
        var all = params
        all["method"] = method
        all["api_key"] = apiKey
        if let sessionKey { all["sk"] = sessionKey }
        if signed { all["api_sig"] = AudioscrobblerSignature.sign(all, secret: apiSecret) }
        all["format"] = "json"

        var request: URLRequest
        if get {
            var components = URLComponents(url: apiURL, resolvingAgainstBaseURL: false)!
            components.queryItems = all.sorted { $0.key < $1.key }.map { URLQueryItem(name: $0.key, value: $0.value) }
            request = URLRequest(url: components.url!)
            request.httpMethod = "GET"
        } else {
            request = URLRequest(url: apiURL)
            request.httpMethod = "POST"
            request.setValue("application/x-www-form-urlencoded; charset=utf-8", forHTTPHeaderField: "Content-Type")
            request.httpBody = FormEncoding.encode(all)
        }

        let data: Data, response: HTTPURLResponse
        do { (data, response) = try await transport.send(request) }
        catch { throw ScrobbleError.transient(error.localizedDescription) }

        let object = (try? JSONSerialization.jsonObject(with: data)) as? [String: Any]
        if let object, let code = Self.int(object["error"]) {
            throw AudioscrobblerCallError(code: code, message: object["message"] as? String ?? "Error \(code)")
        }
        switch response.statusCode {
        case 200..<300:
            guard let object else { throw ScrobbleError.transient("Unreadable response from \(apiURL.host ?? "server")") }
            return object
        case 429: throw ScrobbleError.rateLimited(retryAfter: nil)
        default: throw ScrobbleError.transient("HTTP \(response.statusCode)")
        }
    }

    static func mapError(code: Int, message: String) -> ScrobbleError {
        switch code {
        case 9: .signedOut
        case 10, 13, 26: .keyUnusable(code: code)
        case 11, 16: .transient(message)
        case 29: .rateLimited(retryAfter: nil)
        default: .permanent(message)
        }
    }

    /// Last.fm sends numbers as either JSON numbers or strings.
    static func int(_ value: Any?) -> Int? {
        if let n = value as? Int { return n }
        if let s = value as? String { return Int(s) }
        return nil
    }

    /// Last.fm returns a single object instead of a one-element array.
    static func array(_ value: Any?) -> [[String: Any]] {
        if let array = value as? [[String: Any]] { return array }
        if let object = value as? [String: Any] { return [object] }
        return []
    }
}

struct AudioscrobblerCallError: Error {
    let code: Int
    let message: String
    var scrobbleError: ScrobbleError { AudioscrobblerAPI.mapError(code: code, message: message) }
}

extension Error {
    /// Converts any error thrown by `AudioscrobblerAPI.call` into a `ScrobbleError`.
    var audioscrobblerError: ScrobbleError {
        if let call = self as? AudioscrobblerCallError { return call.scrobbleError }
        return asScrobbleError
    }
}

import Foundation
import ScrobbleCore

public struct AudioscrobblerSession: Sendable, Equatable {
    public var sessionKey: String
    public var username: String
    public init(sessionKey: String, username: String) { self.sessionKey = sessionKey; self.username = username }
}

public enum AudioscrobblerAuthError: Error, Equatable, Sendable {
    case notAuthorizedYet
    case tokenExpired
    case invalidCredentials(String)
    case failed(ScrobbleError)
}

/// Browser sign-in (preferred, no password in the app) and username/password fallback.
public struct AudioscrobblerAuth: Sendable {
    let api: AudioscrobblerAPI

    public init(apiURL: URL, apiKey: String, apiSecret: String, transport: any HTTPTransport) {
        api = AudioscrobblerAPI(apiURL: apiURL, apiKey: apiKey, apiSecret: apiSecret, transport: transport)
    }

    public func getToken() async throws -> String {
        let object = try await perform { try await api.call(method: "auth.getToken", params: [:]) }
        guard let token = object["token"] as? String else { throw AudioscrobblerAuthError.failed(.transient("No token")) }
        return token
    }

    public func authorizationURL(webAuthURL: URL, token: String) -> URL {
        var components = URLComponents(url: webAuthURL, resolvingAgainstBaseURL: false)!
        components.queryItems = [URLQueryItem(name: "api_key", value: api.apiKey), URLQueryItem(name: "token", value: token)]
        return components.url!
    }

    /// Throws `.notAuthorizedYet` until the user approves in the browser; poll every 3 s.
    public func getSession(token: String) async throws -> AudioscrobblerSession {
        try await session(from: perform { try await api.call(method: "auth.getSession", params: ["token": token]) })
    }

    public func getMobileSession(username: String, password: String) async throws -> AudioscrobblerSession {
        let trimmed = username.trimmingCharacters(in: .whitespacesAndNewlines)
        return try await session(from: perform {
            try await api.call(method: "auth.getMobileSession", params: ["username": trimmed, "password": password])
        })
    }

    private func session(from object: [String: Any]) throws -> AudioscrobblerSession {
        guard let session = object["session"] as? [String: Any], let key = session["key"] as? String,
              let name = session["name"] as? String else {
            throw AudioscrobblerAuthError.failed(.transient("No session in response"))
        }
        return AudioscrobblerSession(sessionKey: key, username: name)
    }

    private func perform(_ body: () async throws -> [String: Any]) async throws -> [String: Any] {
        do { return try await body() }
        catch let error as AudioscrobblerCallError {
            switch error.code {
            case 14: throw AudioscrobblerAuthError.notAuthorizedYet
            case 15: throw AudioscrobblerAuthError.tokenExpired
            case 4: throw AudioscrobblerAuthError.invalidCredentials(error.message)
            default: throw AudioscrobblerAuthError.failed(error.scrobbleError)
            }
        } catch {
            throw AudioscrobblerAuthError.failed(error.asScrobbleError)
        }
    }
}

import Foundation
import ScrobbleCore

public struct AudioscrobblerClient: Scrobbler {
    public let maxBatchSize = 50
    public let maxScrobbleAge: TimeInterval? = 14 * 86_400

    private let api: AudioscrobblerAPI
    private let sessionKey: String
    private let username: String

    public init(apiURL: URL, apiKey: String, apiSecret: String, sessionKey: String, username: String,
                transport: any HTTPTransport) {
        api = AudioscrobblerAPI(apiURL: apiURL, apiKey: apiKey, apiSecret: apiSecret, transport: transport)
        self.sessionKey = sessionKey
        self.username = username
    }

    public func nowPlaying(_ track: Track) async throws {
        var params = ["artist": track.artist, "track": track.title]
        if let album = track.album { params["album"] = album }
        // No duration: Last.fm would expire now playing after it (#47).
        do { _ = try await api.call(method: "track.updateNowPlaying", params: params, sessionKey: sessionKey) }
        catch { throw error.audioscrobblerError }
    }

    public func scrobble(_ items: [ScrobbleItem]) async throws -> [ScrobbleItemResult] {
        var params: [String: String] = [:]
        for (index, item) in items.enumerated() {
            params["artist[\(index)]"] = item.track.artist
            params["track[\(index)]"] = item.track.title
            params["timestamp[\(index)]"] = String(Int64(item.date.timeIntervalSince1970))
            params["chosenByUser[\(index)]"] = "0"
            if let album = item.track.album { params["album[\(index)]"] = album }
        }
        let object: [String: Any]
        do { object = try await api.call(method: "track.scrobble", params: params, sessionKey: sessionKey) }
        catch { throw error.audioscrobblerError }

        let scrobbles = AudioscrobblerAPI.array((object["scrobbles"] as? [String: Any])?["scrobble"])
        guard scrobbles.count == items.count else {
            throw ScrobbleError.transient("Expected \(items.count) results, got \(scrobbles.count)")
        }
        return scrobbles.map { scrobble in
            let ignored = scrobble["ignoredMessage"] as? [String: Any]
            let code = AudioscrobblerAPI.int(ignored?["code"]) ?? 0
            let text = (ignored?["#text"] as? String).flatMap { $0.isEmpty ? nil : $0 }
            switch code {
            case 0: return .accepted
            case 5: return .dailyLimit
            case 1: return .ignored(text ?? "Artist was ignored")
            case 2: return .ignored(text ?? "Track was ignored")
            case 3: return .ignored(text ?? "Timestamp too old")
            case 4: return .ignored(text ?? "Timestamp too new")
            default: return .ignored(text ?? "Ignored (code \(code))")
            }
        }
    }

    public func isOtherPlayerActive(excluding ours: Track?) async throws -> Bool {
        let object: [String: Any]
        do {
            object = try await api.call(method: "user.getRecentTracks", params: ["user": username, "limit": "1"],
                                        signed: false, get: true)
        } catch { throw error.audioscrobblerError }
        let tracks = AudioscrobblerAPI.array((object["recenttracks"] as? [String: Any])?["track"])
        guard let playing = tracks.first(where: { ($0["@attr"] as? [String: Any])?["nowplaying"] as? String == "true" }) else {
            return false
        }
        let artistObject = playing["artist"] as? [String: Any]
        let artist = artistObject?["#text"] as? String ?? artistObject?["name"] as? String ?? ""
        let title = playing["name"] as? String ?? ""
        if let ours, Track(artist: artist, title: title).matchKey == ours.matchKey { return false }
        return true
    }
}

        let url = apiURL.appendingPathComponent("1/user").appendingPathComponent(username).appendingPathComponent("playing-now")
        let object = try await Self.request(url, token: token, method: "GET", body: nil, transport: transport)
        let listens = ((object["payload"] as? [String: Any])?["listens"] as? [[String: Any]]) ?? []
        guard let metadata = listens.first?["track_metadata"] as? [String: Any] else { return false }
        let info = metadata["additional_info"] as? [String: Any]
        if info?["submission_client"] as? String == Self.clientName { return false }
        let track = Track(artist: metadata["artist_name"] as? String ?? "", title: metadata["track_name"] as? String ?? "")
        if let ours, ours.matchKey == track.matchKey { return false }
        return true
    }

    /// Deletes a listen we submitted (#7). Needs the listen's msid, which submit-listens doesn't return.
    public func remove(listenedAt date: Date, track: Track) async throws {
        let seconds = Int(date.timeIntervalSince1970)
        var components = URLComponents(url: apiURL.appendingPathComponent("1/user").appendingPathComponent(username)
            .appendingPathComponent("listens"), resolvingAgainstBaseURL: false)!
        components.queryItems = [URLQueryItem(name: "max_ts", value: String(seconds + 1)), URLQueryItem(name: "count", value: "10")]
        let object = try await Self.request(components.url!, token: token, method: "GET", body: nil, transport: transport)
        let listens = ((object["payload"] as? [String: Any])?["listens"] as? [[String: Any]]) ?? []
        let match = listens.first { listen in
            let metadata = listen["track_metadata"] as? [String: Any]
            let candidate = Track(artist: metadata?["artist_name"] as? String ?? "", title: metadata?["track_name"] as? String ?? "")
            return listen["listened_at"] as? Int == seconds && candidate.matchKey == track.matchKey
        }
        guard let msid = match?["recording_msid"] as? String else { throw ScrobbleError.permanent("Listen not found") }
        _ = try await Self.request(apiURL.appendingPathComponent("1/delete-listen"), token: token, method: "POST",
                                   body: ["listened_at": seconds, "recording_msid": msid], transport: transport)
    }

    private func submit(type: String, listens: [[String: Any]]) async throws -> [String: Any] {
        try await Self.request(apiURL.appendingPathComponent("1/submit-listens"), token: token, method: "POST",
                               body: ["listen_type": type, "payload": listens], transport: transport)
    }

    private func listen(_ track: Track, at date: Date?) -> [String: Any] {
        var metadata: [String: Any] = [
            "artist_name": track.artist,
            "track_name": track.title,
            "additional_info": ["submission_client": Self.clientName, "submission_client_version": clientVersion,
                                "media_player": "Shazam"],
        ]
        if let album = track.album { metadata["release_name"] = album }
        var listen: [String: Any] = ["track_metadata": metadata]
        if let date { listen["listened_at"] = Int(date.timeIntervalSince1970) }
        return listen
    }

    private static func request(_ url: URL, token: String, method: String, body: [String: Any]?,
                                transport: any HTTPTransport) async throws -> [String: Any] {
        var request = URLRequest(url: url)
        request.httpMethod = method
        request.setValue("Token \(token)", forHTTPHeaderField: "Authorization")
        if let body {
            request.setValue("application/json", forHTTPHeaderField: "Content-Type")
            request.httpBody = try JSONSerialization.data(withJSONObject: body)
        }
        let data: Data, response: HTTPURLResponse
        do { (data, response) = try await transport.send(request) }
        catch { throw ScrobbleError.transient(error.localizedDescription) }
        let object = (try? JSONSerialization.jsonObject(with: data)) as? [String: Any] ?? [:]
        switch response.statusCode {
        case 200..<300: return object
        case 401: throw ScrobbleError.signedOut
        case 429:
            let reset = response.value(forHTTPHeaderField: "X-RateLimit-Reset-In").flatMap(TimeInterval.init)
            throw ScrobbleError.rateLimited(retryAfter: reset)
        case 400..<500: throw ScrobbleError.permanent(object["error"] as? String ?? "Rejected (HTTP \(response.statusCode))")
        default: throw ScrobbleError.transient("HTTP \(response.statusCode)")
        }
    }
}

import Foundation
import Security

public protocol SecretStore: Sendable {
    func get(_ name: String) throws -> String?
    func set(_ value: String?, for name: String) throws
}

public enum SecretField: String, Sendable, CaseIterable {
    case sessionKey, token, apiKey, apiSecret
}

public struct KeychainError: Error, Equatable {
    public let status: OSStatus
}

/// Generic-password items in the login keychain. Access is tied to the app's designated
/// requirement, so the stable signing certificate keeps it prompt-free across updates (§11).
public struct KeychainSecretStore: SecretStore {
    public let service: String

    public init(service: String = "ShazamScrobbler") { self.service = service }

    public func get(_ name: String) throws -> String? {
        var query = baseQuery(name)
        query[kSecReturnData as String] = true
        query[kSecMatchLimit as String] = kSecMatchLimitOne
        var item: CFTypeRef?
        let status = SecItemCopyMatching(query as CFDictionary, &item)
        if status == errSecItemNotFound { return nil }
        guard status == errSecSuccess, let data = item as? Data else { throw KeychainError(status: status) }
        return String(decoding: data, as: UTF8.self)
    }

    public func set(_ value: String?, for name: String) throws {
        let query = baseQuery(name)
        guard let value else {
            let status = SecItemDelete(query as CFDictionary)
            guard status == errSecSuccess || status == errSecItemNotFound else { throw KeychainError(status: status) }
            return
        }
        let data = Data(value.utf8)
        var status = SecItemUpdate(query as CFDictionary, [kSecValueData as String: data] as CFDictionary)
        if status == errSecItemNotFound {
            var add = query
            add[kSecValueData as String] = data
            add[kSecAttrAccessible as String] = kSecAttrAccessibleAfterFirstUnlock
            add[kSecAttrLabel as String] = "ShazamScrobbler"
            status = SecItemAdd(add as CFDictionary, nil)
        }
        guard status == errSecSuccess else { throw KeychainError(status: status) }
    }

    private func baseQuery(_ name: String) -> [String: Any] {
        [kSecClass as String: kSecClassGenericPassword,
         kSecAttrService as String: service,
         kSecAttrAccount as String: name]
    }
}

public final class InMemorySecretStore: SecretStore, @unchecked Sendable {
    private let lock = NSLock()
    private var values: [String: String] = [:]

    public init() {}

    public func get(_ name: String) throws -> String? { lock.withLock { values[name] } }
    public func set(_ value: String?, for name: String) throws { lock.withLock { values[name] = value } }
}

import Foundation

/// Non-secret account fields in UserDefaults (key "accounts.v2"); secrets in a SecretStore.
public final class AccountStore: @unchecked Sendable {
    static let defaultsKey = "accounts.v2"
    private let defaults: UserDefaults
    private let secrets: any SecretStore

    public init(defaults: UserDefaults = .standard, secrets: any SecretStore = KeychainSecretStore()) {
        self.defaults = defaults
        self.secrets = secrets
    }

    public func load() -> [Account] {
        guard let data = defaults.data(forKey: Self.defaultsKey) else { return [] }
        return (try? JSONDecoder().decode([Account].self, from: data)) ?? []
    }

    public func upsert(_ account: Account) {
        var accounts = load()
        if let index = accounts.firstIndex(where: { $0.id == account.id }) { accounts[index] = account }
        else { accounts.append(account) }
        save(accounts)
    }

    public func remove(_ id: AccountID) throws {
        save(load().filter { $0.id != id })
        for field in SecretField.allCases { try secrets.set(nil, for: Self.name(field, id)) }
    }

    public func secret(_ field: SecretField, for id: AccountID) -> String? {
        try? secrets.get(Self.name(field, id))
    }

    public func setSecret(_ value: String?, _ field: SecretField, for id: AccountID) throws {
        try secrets.set(value, for: Self.name(field, id))
    }

    private func save(_ accounts: [Account]) {
        defaults.set(try? JSONEncoder().encode(accounts), forKey: Self.defaultsKey)
    }

    static func name(_ field: SecretField, _ id: AccountID) -> String { "\(id.rawValue).\(field.rawValue)" }
}

    public var nowPlayingError: ScrobbleError?

    public private(set) var nowPlayingTracks: [Track] = []
    public private(set) var otherPlayerChecks: [Track?] = []

    public func setOtherPlayerActive(_ value: Bool) { otherPlayerActive = value }
    public func setNowPlayingError(_ error: ScrobbleError?) { nowPlayingError = error }

    public func nowPlaying(_ track: Track) async throws {
        if let nowPlayingError { throw nowPlayingError }

        case let .failure(error): throw error
        }
    }

```swift
import Foundation
import os

public struct DeliveryReport: Sendable, Equatable {
    public var problems: [AccountID: AccountProblem] = [:]
    public var scrobbled = 0
    public var nextWake: Date?
    public init() {}
}

/// Sends now-playing updates and pending scrobbles, one account at a time (spec §7).
public actor Delivery {
    private let store: StateStore
    private let time: any TimeSource
    private let random: @Sendable () -> Double
    private let log = Logger(subsystem: "ShazamScrobbler", category: "delivery")

    public init(store: StateStore, time: any TimeSource,
                random: @escaping @Sendable () -> Double = { Double.random(in: 0..<1) }) {
        self.store = store
        self.time = time
        self.random = random
    }

    public func run(scrobblers: [AccountID: any Scrobbler], nowPlaying: [NowPlayingRequest],
                    paused: Bool) async -> DeliveryReport {
        var report = DeliveryReport()
        if !paused {
            for (account, scrobbler) in scrobblers.sorted(by: { $0.key.rawValue < $1.key.rawValue }) {
                if let problem = (try? store.heldProblems())?[account] {
                    report.problems[account] = problem
                    continue
                }
                await sendNowPlaying(nowPlaying.filter { $0.account == account }, account: account,
                                     scrobbler: scrobbler, report: &report)
                guard report.problems[account] == nil else { continue }
                await sendPending(account: account, scrobbler: scrobbler, report: &report)
                try? store.advanceCursor(for: account)
            }
        }
        report.nextWake = try? store.nextRetryDate()
        return report
    }

    private func sendNowPlaying(_ requests: [NowPlayingRequest], account: AccountID, scrobbler: any Scrobbler,
                                report: inout DeliveryReport) async {
        for request in requests {
            do {
                if !request.isRefresh {
                    let ours = (try? store.lastNowPlaying())?[account].flatMap { try? store.track(for: $0.key) }
                    if try await scrobbler.isOtherPlayerActive(excluding: ours) {
                        log.info("Another player is active for \(account.rawValue, privacy: .public); skipping tag")
                        try? store.set(.skipped(.otherPlayer), key: request.tag.key, account: account, now: time.now)
                        continue
                    }
                }
                try await scrobbler.nowPlaying(request.tag.track)
                try? store.setNowPlaying(NowPlayingRecord(key: request.tag.key, sentAt: time.now), for: account)
            } catch {
                let scrobbleError = error.asScrobbleError
                if let problem = DeliveryPolicy.problem(for: scrobbleError) {
                    report.problems[account] = problem
                    try? store.hold(account: account, problem: problem, now: time.now)
                    return
                }
                log.notice("Now playing failed for \(account.rawValue, privacy: .public): \(String(describing: scrobbleError), privacy: .public)")
            }
        }
    }

    private func sendPending(account: AccountID, scrobbler: any Scrobbler, report: inout DeliveryReport) async {
        while true {
            guard let items = try? store.pending(account: account, dueBy: time.now, limit: scrobbler.maxBatchSize),
                  !items.isEmpty else { return }
            let now = time.now
            var sendable: [PendingItem] = []
            for item in items {
                if let maxAge = scrobbler.maxScrobbleAge, now.timeIntervalSince(item.date) > maxAge {
                    try? store.set(.ignored("Too old for this service (over 14 days)"), key: item.key, account: account, now: now)
                } else {
                    sendable.append(item)
                }
            }
            guard !sendable.isEmpty else { continue }
            if await send(sendable, account: account, scrobbler: scrobbler, report: &report) == .stop { return }
        }
    }

    private enum Outcome { case proceed, stop }

    private func send(_ items: [PendingItem], account: AccountID, scrobbler: any Scrobbler,
                      report: inout DeliveryReport) async -> Outcome {
        let now = time.now
        do {
            let results = try await scrobbler.scrobble(items.map { ScrobbleItem(key: $0.key, track: $0.track, date: $0.date) })
            for (item, result) in zip(items, results) {
                switch result {
                case .accepted:
                    try? store.set(.scrobbled(at: now), key: item.key, account: account, now: now)
                    report.scrobbled += 1
                case let .ignored(reason):
                    try? store.set(.ignored(reason), key: item.key, account: account, now: now)
                case .dailyLimit:
                    let attempt: Int
                    if case let .retry(previous, _) = item.state { attempt = previous + 1 } else { attempt = 1 }
                    try? store.set(.retry(attempt: attempt, nextAt: Backoff.nextUTCMidnight(after: now)),
                                   key: item.key, account: account, now: now)
                }
            }
            return .proceed
        } catch {
            let scrobbleError = error.asScrobbleError
            if let problem = DeliveryPolicy.problem(for: scrobbleError) {
                report.problems[account] = problem
                try? store.hold(account: account, problem: problem, now: now)
                return .stop
            }
            if case .permanent = scrobbleError, items.count > 1 {
                for item in items {
                    if await send([item], account: account, scrobbler: scrobbler, report: &report) == .stop { return .stop }
                }
                return .proceed
            }
            for item in items {
                try? store.set(DeliveryPolicy.state(after: scrobbleError, previous: item.state, now: now, random: random()),
                               key: item.key, account: account, now: now)
            }
            if case .permanent = scrobbleError { return .proceed }
            log.notice("Delivery paused for \(account.rawValue, privacy: .public): \(String(describing: scrobbleError), privacy: .public)")
            return .stop
        }
    }
}

import Foundation

/// Serializes scans: a trigger during a running scan queues exactly one more run.
public actor RescanGate {
    private var running = false
    private var pending = false

    public init() {}

    public func trigger(_ body: @Sendable () async -> Void) async {
        if running {
            pending = true
            return
        }
        running = true
        repeat {
            pending = false
            await body()
        } while pending
        running = false
    }
}

import Foundation

public struct NowPlayingInfo: Sendable, Equatable {
    public var tag: ShazamTag
    public var deadline: Date
}

public struct Snapshot: Sendable, Equatable {
    public var libraryStatus: LibraryStatus
    public var recent: [ShazamTag]
    public var states: [TagKey: [AccountID: DeliveryState]]
    public var excluded: Set<TagKey>
    public var problems: [AccountID: AccountProblem]
    public var waitingCount: Int
    public var nowPlaying: NowPlayingInfo?
    public var nextWake: Date?
    public var paused: Bool

    public static let empty = Snapshot(libraryStatus: .noLibraryYet, recent: [], states: [:], excluded: [],
                                       problems: [:], waitingCount: 0, nowPlaying: nil, nextWake: nil, paused: false)
}

/// One scan: read Shazam → engine → store → delivery → snapshot for the UI.
public actor ScanCycle {
    private let source: any TagSource
    private let store: StateStore
    private let delivery: Delivery
    private let time: any TimeSource

    public init(source: any TagSource, store: StateStore, delivery: Delivery, time: any TimeSource) {
        self.source = source
        self.store = store
        self.delivery = delivery
        self.time = time
    }

    public func run(accounts: [Account], scrobblers: [AccountID: any Scrobbler],
                    settings: EngineSettings, recentLimit: Int = 20) async -> Snapshot {
        let now = time.now
        for account in accounts where (try? store.cursor(for: account.id)) == nil {
            try? store.setCursor(account.addedAt, for: account.id)
        }
        var cursors = currentCursors(accounts)
        var since = cursors.map(\.since).min() ?? now
        var result = source.read(since: since, recentLimit: recentLimit)

        if result.status == .ok, (try? LegacyMigration.resolvePending(store: store, source: source)) == true {
            cursors = currentCursors(accounts)
            since = cursors.map(\.since).min() ?? now
            result = source.read(since: since, recentLimit: recentLimit)
        }

        var requests: [NowPlayingRequest] = []
        var engineWake: Date?
        if result.status == .ok, !cursors.isEmpty {
            try? store.record(result.tagsSince)
            let choices = (try? store.choices()) ?? (excluded: [], forced: [])
            let output = ScrobbleEngine.evaluate(EngineInput(
                tags: result.tagsSince, now: now, settings: settings, accounts: cursors,
                states: (try? store.states(since: since)) ?? [:],
                excluded: choices.excluded, forced: choices.forced,
                lastNowPlaying: (try? store.lastNowPlaying()) ?? [:]))
            try? store.apply(output.transitions, now: now)
            requests = output.nowPlaying
            engineWake = output.nextWake
        }

        let report = await delivery.run(scrobblers: scrobblers, nowPlaying: requests, paused: settings.paused)

        let states = (try? store.states(for: result.recent.map(\.key))) ?? [:]
        let nowPlaying = result.recent.first.flatMap { tag -> NowPlayingInfo? in
            for state in Array(states[tag.key]?.values ?? [:].values) {
                if case let .nowPlaying(deadline) = state, deadline > now { return NowPlayingInfo(tag: tag, deadline: deadline) }
            }
            return nil
        }
        var problems = (try? store.heldProblems()) ?? [:]
        problems.merge(report.problems) { _, new in new }

        return Snapshot(
            libraryStatus: result.status, recent: result.recent, states: states,
            excluded: (try? store.choices().excluded) ?? [], problems: problems,
            waitingCount: (try? store.waitingCount()) ?? 0, nowPlaying: nowPlaying,
            nextWake: [engineWake, report.nextWake].compactMap { $0 }.min(), paused: settings.paused)
    }

    private func currentCursors(_ accounts: [Account]) -> [AccountCursor] {
        accounts.compactMap { account in
            (try? store.cursor(for: account.id)).map { AccountCursor(id: account.id, since: $0) }
        }
    }
}

import Foundation

public enum LegacyMigration {
    public static let doneKey = "migratedToV2"
    private static let legacyKeys = ["session", "username", "lastScrobble", "notToScrobble", "scrobbling"]

    /// Step 1, at launch. Returns the created Last.fm account, if 1.x was signed in.
    @discardableResult
    public static func migrateDefaults(defaults: UserDefaults, accounts: AccountStore, settings: SettingsStore,
                                       store: StateStore, now: Date) throws -> Account? {
        guard !defaults.bool(forKey: doneKey) else { return nil }
        var created: Account?
        if let session = defaults.string(forKey: "session"), !session.isEmpty {
            let account = Account(id: .new(), preset: .lastfm, username: defaults.string(forKey: "username") ?? "",
                                  apiURL: ServicePreset.lastfm.defaultAPIURL!, webAuthURL: ServicePreset.lastfm.defaultWebAuthURL,
                                  keyMode: .builtIn, addedAt: now)
            accounts.upsert(account)
            try accounts.setSecret(session, .sessionKey, for: account.id)
            try store.setCursor(now, for: account.id)
            try store.setMeta("legacy.account", account.id.rawValue)
            if let pk = defaults.object(forKey: "lastScrobble") as? Int {
                try store.setMeta("legacy.lastScrobblePK", String(pk))
            }
            created = account
        }
        if let excluded = defaults.array(forKey: "notToScrobble") as? [Int], !excluded.isEmpty {
            try store.setMeta("legacy.notToScrobble", excluded.map(String.init).joined(separator: ","))
        }
        if defaults.object(forKey: "scrobbling") != nil, defaults.integer(forKey: "scrobbling") == 0 {
            settings.engineSettings = EngineSettings(paused: true, pauseMode: .keep,
                                                     minPlayTime: settings.engineSettings.minPlayTime)
        }
        legacyKeys.forEach(defaults.removeObject(forKey:))
        defaults.set(true, forKey: doneKey)
        return created
    }

    /// Step 2, on the first scan that can read Shazam. Returns true if it changed anything.
    public static func resolvePending(store: StateStore, source: any TagSource) throws -> Bool {
        let accountID = try store.meta("legacy.account").map(AccountID.init(rawValue:))
        let lastPK = try store.meta("legacy.lastScrobblePK").flatMap(Int64.init)
        let excludedPKs = try store.meta("legacy.notToScrobble")?.split(separator: ",").compactMap { Int64($0) } ?? []
        guard accountID != nil || lastPK != nil || !excludedPKs.isEmpty else { return false }

        let found = source.tags(withPKs: excludedPKs + (lastPK.map { [$0] } ?? []))
        if let accountID, let lastPK, let tag = found[lastPK] {
            try store.setCursor(tag.date, for: accountID)
        }
        for pk in excludedPKs {
            if let tag = found[pk] { try store.setChoice(.exclude, for: tag.key) }
        }
        for key in ["legacy.account", "legacy.lastScrobblePK", "legacy.notToScrobble"] { try store.setMeta(key, nil) }
        return true
    }
}

import Foundation

public enum AggregateStatus: Equatable, Sendable {
    case none, done, partial, pending, skipped
}

public struct AccountLine: Equatable, Sendable {
    public var account: Account
    /// `nil` when the tag predates the account.
    public var state: DeliveryState?
}

public struct SongRow: Equatable, Sendable {
    public var key: TagKey
    public var track: Track
    public var date: Date
    public var aggregate: AggregateStatus
    public var lines: [AccountLine]
    public var isExcluded: Bool
}

public struct NowPlayingRow: Equatable, Sendable {
    public var row: SongRow
    public var deadline: Date
}

public struct ProblemRow: Equatable, Sendable {
    public var account: Account
    public var problem: AccountProblem
    public init(account: Account, problem: AccountProblem) { self.account = account; self.problem = problem }
}

public enum LibraryNotice: Equatable, Sendable {
    case waitingForShazam, notInstalled, accessDenied
    case unsupported(String)
    case unreadable(String)
}

public struct MenuContent: Equatable, Sendable {
    public var nowPlaying: NowPlayingRow?
    public var recent: [SongRow]
    public var problems: [ProblemRow]
    public var library: LibraryNotice?
    public var paused: Bool
    public var waitingCount: Int
}

public enum MenuModel {
    public static let recentSlots = 20
    public static let problemSlots = 5

    public static func content(snapshot: Snapshot, accounts: [Account]) -> MenuContent {
        func row(_ tag: ShazamTag) -> SongRow {
            let lines = accounts.map { AccountLine(account: $0, state: snapshot.states[tag.key]?[$0.id]) }
            return SongRow(key: tag.key, track: tag.track, date: tag.date, aggregate: aggregate(lines.map(\.state)),
                           lines: lines, isExcluded: snapshot.excluded.contains(tag.key))
        }
        let nowPlaying = snapshot.nowPlaying.map { NowPlayingRow(row: row($0.tag), deadline: $0.deadline) }
        let recent = snapshot.recent.filter { $0.key != nowPlaying?.row.key }.prefix(recentSlots).map(row)
        let problems = snapshot.problems.compactMap { id, problem in
            accounts.first { $0.id == id }.map { ProblemRow(account: $0, problem: problem) }
        }.sorted { $0.account.id.rawValue < $1.account.id.rawValue }

        return MenuContent(nowPlaying: nowPlaying, recent: Array(recent), problems: Array(problems.prefix(problemSlots)),
                           library: notice(for: snapshot.libraryStatus), paused: snapshot.paused,
                           waitingCount: snapshot.waitingCount)
    }

    public static func aggregate(_ states: [DeliveryState?]) -> AggregateStatus {
        let present = states.compactMap { $0 }
        guard !present.isEmpty else { return .none }
        let scrobbled = present.filter { if case .scrobbled = $0 { true } else { false } }.count
        if scrobbled == present.count { return .done }
        if scrobbled > 0 { return .partial }
        if present.allSatisfy(\.isFinal) { return .skipped }
        return .pending
    }

    /// Indices whose content differs; the menu updates only those items (§6.2).
    public static func changedSlots<T: Equatable>(old: [T?], new: [T?]) -> [Int] {
        (0..<max(old.count, new.count)).filter { index in
            (index < old.count ? old[index] : nil) != (index < new.count ? new[index] : nil)
        }
    }

    public static func countdown(to deadline: Date, now: Date) -> String {
        let seconds = max(0, Int(deadline.timeIntervalSince(now).rounded(.up)))
        return String(format: "%d:%02d", seconds / 60, seconds % 60)
    }

    static func notice(for status: LibraryStatus) -> LibraryNotice? {
        switch status {
        case .ok: nil
        case .noLibraryYet: .waitingForShazam
        case .notInstalled: .notInstalled
        case .accessDenied: .accessDenied
        case let .unsupportedSchema(detail): .unsupported(detail)
        case let .unreadable(detail): .unreadable(detail)
        }
    }
}

import Foundation
import os

/// Watches a directory and named files inside it; re-arms after deletes, renames and
/// permission failures. All state lives on a private serial queue.
public final class FolderWatcher: @unchecked Sendable {
    private let directory: URL
    private let fileNames: [String]
    private let debounce: TimeInterval
    private let rearmInterval: TimeInterval
    private let onChange: @Sendable () -> Void
    private let queue = DispatchQueue(label: "ShazamScrobbler.FolderWatcher")
    private static let log = Logger(subsystem: "ShazamScrobbler", category: "shazam")

    private var directorySource: DispatchSourceFileSystemObject?
    private var fileSources: [String: DispatchSourceFileSystemObject] = [:]
    private var rearmTimer: DispatchSourceTimer?
    private var pending: DispatchWorkItem?
    private var stopped = true

    public init(directory: URL, fileNames: [String], debounce: TimeInterval = 0.5, rearmInterval: TimeInterval = 5,
                onChange: @escaping @Sendable () -> Void) {
        self.directory = directory
        self.fileNames = fileNames
        self.debounce = debounce
        self.rearmInterval = rearmInterval
        self.onChange = onChange
    }

    public var isWatchingDirectory: Bool { queue.sync { directorySource != nil } }

    public func start() {
        queue.async {
            self.stopped = false
            self.arm()
        }
    }

    public func stop() {
        queue.sync {
            stopped = true
            cancelAll()
        }
    }

    private func arm() {
        guard !stopped else { return }
        if directorySource == nil {
            directorySource = makeSource(path: directory.path) { [weak self] flags in self?.directoryChanged(flags) }
        }
        if directorySource != nil {
            for name in fileNames where fileSources[name] == nil {
                fileSources[name] = makeSource(path: directory.appendingPathComponent(name).path) { [weak self] flags in
                    self?.fileChanged(name, flags)
                }
            }
        }
        if directorySource == nil || fileSources.count < fileNames.count { scheduleRearm() } else { cancelRearm() }
    }

    private func makeSource(path: String, handler: @escaping @Sendable (DispatchSource.FileSystemEvent) -> Void)
        -> DispatchSourceFileSystemObject? {
        let fd = open(path, O_EVTONLY)
        guard fd >= 0 else {
            let code = errno
            if code != ENOENT { Self.log.notice("Cannot watch \(path, privacy: .private): errno \(code)") }
            return nil
        }
        let source = DispatchSource.makeFileSystemObjectSource(
            fileDescriptor: fd, eventMask: [.write, .extend, .delete, .rename, .attrib, .link, .revoke], queue: queue)
        source.setEventHandler { [weak source] in
            guard let source else { return }
            handler(source.data)
        }
        source.setCancelHandler { close(fd) }
        source.resume()
        return source
    }

    private func directoryChanged(_ flags: DispatchSource.FileSystemEvent) {
        if !flags.isDisjoint(with: [.delete, .rename, .revoke]) {
            cancelAll()
        }
        arm()
        fire()
    }

    private func fileChanged(_ name: String, _ flags: DispatchSource.FileSystemEvent) {
        if !flags.isDisjoint(with: [.delete, .rename, .revoke]) {
            fileSources.removeValue(forKey: name)?.cancel()
            arm()
        }
        fire()
    }

    private func fire() {
        pending?.cancel()
        let item = DispatchWorkItem { [onChange] in onChange() }
        pending = item
        queue.asyncAfter(deadline: .now() + debounce, execute: item)
    }

    private func scheduleRearm() {
        guard rearmTimer == nil, !stopped else { return }
        let timer = DispatchSource.makeTimerSource(queue: queue)
        timer.schedule(deadline: .now() + rearmInterval, repeating: rearmInterval)
        timer.setEventHandler { [weak self] in
            guard let self else { return }
            let hadDirectory = self.directorySource != nil
            let hadFiles = self.fileSources.count
            self.arm()
            if (!hadDirectory && self.directorySource != nil) || self.fileSources.count > hadFiles { self.fire() }
        }
        rearmTimer = timer
        timer.resume()
    }

    private func cancelRearm() {
        rearmTimer?.cancel()
        rearmTimer = nil
    }

    private func cancelAll() {
        directorySource?.cancel()
        directorySource = nil
        fileSources.values.forEach { $0.cancel() }
        fileSources = [:]
        cancelRearm()
        pending?.cancel()
    }
}

enum BuiltInLastFmKey {
    /// Injected at build time (App/Config); absent in builds without Secrets.xcconfig.
    static var current: (key: String, secret: String)? {
        guard let key = Bundle.main.object(forInfoDictionaryKey: "LastFmAPIKey") as? String,
              let secret = Bundle.main.object(forInfoDictionaryKey: "LastFmAPISecret") as? String,
              !key.isEmpty, !secret.isEmpty else { return nil }
        return (key, secret)
    }
}

enum ScrobblerFactory {
    static var clientVersion: String {
        Bundle.main.object(forInfoDictionaryKey: "CFBundleShortVersionString") as? String ?? "2"
    }

    static func make(for account: Account, accounts: AccountStore,
                     transport: any HTTPTransport) -> Result<any Scrobbler, AccountProblem> {
        switch account.preset.family {
        case .audioscrobbler:
            guard let credentials = apiCredentials(for: account, accounts: accounts) else { return .failure(.keyUnusable) }
            guard let session = accounts.secret(.sessionKey, for: account.id) else { return .failure(.signedOut) }
            return .success(AudioscrobblerClient(apiURL: account.apiURL, apiKey: credentials.key, apiSecret: credentials.secret,
                                                 sessionKey: session, username: account.username, transport: transport))
        case .listenBrainz:
            guard let token = accounts.secret(.token, for: account.id) else { return .failure(.signedOut) }
            return .success(ListenBrainzClient(apiURL: account.apiURL, token: token, username: account.username,
                                               transport: transport, clientVersion: clientVersion))
        }
    }

    static func apiCredentials(for account: Account, accounts: AccountStore) -> (key: String, secret: String)? {
        switch account.keyMode {
        case .builtIn: return BuiltInLastFmKey.current
        case .own:
            guard let key = accounts.secret(.apiKey, for: account.id),
                  let secret = accounts.secret(.apiSecret, for: account.id) else { return nil }
            return (key, secret)
        }
    }
}

import Combine
import Foundation
import os
import ScrobbleClients
import ScrobbleCore
import ShazamLibrary

@MainActor
final class AppModel: ObservableObject {
    @Published private(set) var snapshot: Snapshot = .empty
    @Published private(set) var accounts: [Account] = []
    @Published var settings: EngineSettings {
        didSet {
            guard settings != oldValue else { return }
            settingsStore.engineSettings = settings
            rescan()
        }
    }
    @Published var notifyNowPlaying: Bool {
        didSet { settingsStore.notifyNowPlaying = notifyNowPlaying }
    }

    let accountStore: AccountStore
    let stateStore: StateStore
    let library = ShazamLibrary()
    let transport = URLSessionTransport()

    private let settingsStore: SettingsStore
    private let scanCycle: ScanCycle
    private let gate = RescanGate()
    private var scrobblers: [AccountID: any Scrobbler] = [:]
    private var configurationProblems: [AccountID: AccountProblem] = [:]
    private var wakeTimer: Timer?
    private let log = Logger(subsystem: "ShazamScrobbler", category: "ui")

    init() throws {
        accountStore = AccountStore()
        settingsStore = SettingsStore()
        stateStore = try StateStore(url: StateStore.defaultURL)
        try LegacyMigration.migrateDefaults(defaults: .standard, accounts: accountStore, settings: settingsStore,
                                            store: stateStore, now: Date())
        settings = settingsStore.engineSettings
        notifyNowPlaying = settingsStore.notifyNowPlaying
        let time = SystemTime()
        scanCycle = ScanCycle(source: library, store: stateStore, delivery: Delivery(store: stateStore, time: time), time: time)
        reloadAccounts()
    }

    // MARK: scanning

    private struct ScanInputs: Sendable {
        var accounts: [Account]
        var scrobblers: [AccountID: any Scrobbler]
        var settings: EngineSettings
    }

    private func scanInputs() -> ScanInputs {
        ScanInputs(accounts: accounts, scrobblers: scrobblers, settings: settings)
    }

    /// Safe to call from anywhere, any number of times: scans are coalesced.
    func rescan() {
        let gate = gate, cycle = scanCycle
        Task { [weak self] in
            await gate.trigger { [weak self] in
                guard let inputs = await self?.scanInputs() else { return }
                let snapshot = await cycle.run(accounts: inputs.accounts, scrobblers: inputs.scrobblers, settings: inputs.settings)
                await self?.publish(snapshot)
            }
        }
    }

    private func publish(_ new: Snapshot) {
        var merged = new
        merged.problems.merge(configurationProblems) { held, _ in held }
        if merged != snapshot { snapshot = merged }
        scheduleWake(at: merged.nextWake)
    }

    private func scheduleWake(at date: Date?) {
        wakeTimer?.invalidate()
        wakeTimer = nil
        guard let date else { return }
        let timer = Timer(fire: max(date, Date().addingTimeInterval(0.5)), interval: 0, repeats: false) { [weak self] _ in
            Task { @MainActor in self?.rescan() }
        }
        RunLoop.main.add(timer, forMode: .common)
        wakeTimer = timer
    }

    // MARK: accounts

    func reloadAccounts() {
        accounts = accountStore.load()
        scrobblers = [:]
        configurationProblems = [:]
        for account in accounts {
            switch ScrobblerFactory.make(for: account, accounts: accountStore, transport: transport) {
            case let .success(scrobbler): scrobblers[account.id] = scrobbler
            case let .failure(problem): configurationProblems[account.id] = problem
            }
        }
        rescan()
    }

    /// After a successful (re-)sign-in or key change: release held scrobbles and reload clients.
    func accountSignedIn(_ account: Account) {
        accountStore.upsert(account)
        try? stateStore.releaseHeld(account: account.id)
        reloadAccounts()
    }

    func removeAccount(_ id: AccountID) {
        do {
            try accountStore.remove(id)
            try stateStore.removeAccount(id)
        } catch {
            log.error("Removing account failed: \(String(describing: error), privacy: .public)")
        }
        reloadAccounts()
    }

    // MARK: user actions

    func togglePause() { settings.paused.toggle() }

    func skipWaiting() {
        _ = try? stateStore.skipAllWaiting(now: Date())
        rescan()
    }

    func setChoice(_ choice: UserChoice?, for key: TagKey) {
        try? stateStore.setChoice(choice, for: key)
        rescan()
    }

    func removeFromListenBrainz(row: SongRow, account: Account) async {
        guard case let .success(scrobbler) = ScrobblerFactory.make(for: account, accounts: accountStore, transport: transport),
              let client = scrobbler as? ListenBrainzClient else { return }
        do {
            try await client.remove(listenedAt: row.date, track: row.track)
            try? stateStore.setChoice(.exclude, for: row.key)
            try? stateStore.set(.skipped(.user), key: row.key, account: account.id, now: Date())
        } catch {
            log.error("Remove from ListenBrainz failed: \(String(describing: error), privacy: .public)")
        }
        rescan()
    }
}

import AppKit
import Network
import ShazamLibrary

/// Every reason to rescan (§4): Shazam folder changes, 60 s timer, wake, network back, fast polling
/// while the Full Disk Access window is open. The model coalesces them.
@MainActor
final class RescanScheduler {
    private let model: AppModel
    private var watcher: FolderWatcher?
    private var timer: Timer?
    private var fastTimer: Timer?
    private let pathMonitor = NWPathMonitor()
    private var wasOnline = true

    init(model: AppModel) { self.model = model }

    func start() {
        let library = model.library
        let watcher = FolderWatcher(directory: library.watchedDirectoryURL, fileNames: ShazamLibrary.watchedFileNames) { [weak self] in
            Task { @MainActor in self?.model.rescan() }
        }
        watcher.start()
        self.watcher = watcher

        timer = makeTimer(every: 60)

        NSWorkspace.shared.notificationCenter.addObserver(
            forName: NSWorkspace.didWakeNotification, object: nil, queue: .main) { [weak self] _ in
            Task { @MainActor in self?.model.rescan() }
        }

        pathMonitor.pathUpdateHandler = { [weak self] path in
            let online = path.status == .satisfied
            Task { @MainActor in
                guard let self else { return }
                if online && !self.wasOnline { self.model.rescan() }
                self.wasOnline = online
            }
        }
        pathMonitor.start(queue: DispatchQueue(label: "ShazamScrobbler.network"))
    }

    func setFastPolling(_ on: Bool) {
        fastTimer?.invalidate()
        fastTimer = on ? makeTimer(every: 2) : nil
    }

    private func makeTimer(every seconds: TimeInterval) -> Timer {
        let timer = Timer(timeInterval: seconds, repeats: true) { [weak self] _ in
            Task { @MainActor in self?.model.rescan() }
        }
        timer.tolerance = seconds / 10
        RunLoop.main.add(timer, forMode: .common)
        return timer
    }
}

import Foundation
import ScrobbleCore

enum Formatting {
    static let maxTitleLength = 60

    static func songTitle(_ track: Track) -> String { "\(track.artist) – \(track.title)" }

    static func truncateMiddle(_ text: String, max: Int = maxTitleLength) -> String {
        guard text.count > max, max > 1 else { return text }
        let head = (max - 1) / 2, tail = max - 1 - head
        return String(text.prefix(head)) + "…" + String(text.suffix(tail))
    }

    static func time(_ date: Date) -> String {
        date.formatted(date: Calendar.current.isDateInToday(date) ? .omitted : .abbreviated, time: .shortened)
    }

    static func serviceName(_ preset: ServicePreset) -> String {
        switch preset {
        case .lastfm: String(localized: "Last.fm")
        case .librefm: String(localized: "Libre.fm")
        case .listenbrainz: String(localized: "ListenBrainz")
        case .customAudioscrobbler: String(localized: "Custom (Last.fm-compatible)")
        case .customListenBrainz: String(localized: "Custom (ListenBrainz-compatible)")
        }
    }

    static func accountName(_ account: Account) -> String {
        switch account.preset {
        case .customAudioscrobbler, .customListenBrainz:
            "\(account.username) @ \(account.apiURL.host ?? account.apiURL.absoluteString)"
        default:
            "\(serviceName(account.preset)) (\(account.username))"
        }
    }

    static func state(_ state: DeliveryState?) -> String {
        guard let state else { return String(localized: "Not sent (added after this tag)") }
        switch state {
        case .waiting: return String(localized: "Waiting")
        case .nowPlaying: return String(localized: "Now playing")
        case let .scrobbled(at): return String(localized: "Scrobbled \(time(at))")
        case .tooShort: return String(localized: "Not played long enough")
        case .skipped(.paused): return String(localized: "Skipped while paused")
        case .skipped(.user): return String(localized: "Not scrobbled (your choice)")
        case .skipped(.otherPlayer): return String(localized: "Skipped: another player was active")
        case .skipped(.duplicate): return String(localized: "Repeat of the previous tag")
        case let .ignored(reason): return String(localized: "Not accepted: \(reason)")
        case .held(.signedOut): return String(localized: "On hold: signed out")
        case .held(.keyUnusable): return String(localized: "On hold: API key not working")
        case let .retry(_, nextAt): return String(localized: "Retrying at \(time(nextAt))")
        }
    }

    static func problem(_ row: ProblemRow) -> String {
        let name = accountName(row.account)
        switch row.problem {
        case .signedOut: return String(localized: "\(name): signed out")
        case .keyUnusable where row.account.keyMode == .builtIn:
            return String(localized: "\(name): key not working. Last.fm may require Pro for this key")
        case .keyUnusable: return String(localized: "\(name): API key not working")
        }
    }

    static func library(_ notice: LibraryNotice) -> String {
        switch notice {
        case .waitingForShazam: String(localized: "Waiting for Shazam's first tag")
        case .notInstalled: String(localized: "Shazam isn't installed: Get Shazam…")
        case .accessDenied: String(localized: "Can't read Shazam: Set Up Access…")
        case .unsupported: String(localized: "This Shazam version isn't supported yet")
        case .unreadable: String(localized: "Can't read Shazam's library right now")
        }
    }

    /// Self-hosted servers on the LAN need macOS's Local Network permission (macOS 15+, §12b).
    static func isLocalNetwork(_ url: URL) -> Bool {
        guard let host = url.host?.lowercased() else { return false }
        if host == "localhost" || host.hasSuffix(".local") { return true }
        let parts = host.split(separator: ".").compactMap { Int($0) }
        guard parts.count == 4 else { return false }
        return parts[0] == 10 || parts[0] == 127 || (parts[0] == 192 && parts[1] == 168)
            || (parts[0] == 172 && (16...31).contains(parts[1])) || (parts[0] == 169 && parts[1] == 254)
    }

    static func symbol(_ status: AggregateStatus) -> String {
        switch status {
        case .done: "checkmark.circle.fill"
        case .partial: "circle.lefthalf.filled"
        case .pending: "clock"
        case .skipped: "nosign"
        case .none: "music.note"
        }
    }

    static func symbolDescription(_ status: AggregateStatus) -> String {
        switch status {
        case .done: String(localized: "Scrobbled")
        case .partial: String(localized: "Scrobbled to some accounts")
        case .pending: String(localized: "Waiting")
        case .skipped: String(localized: "Not scrobbled")
        case .none: String(localized: "No accounts")
        }
    }
}

enum AddAccountMode: Identifiable {
    case add
    case reauthenticate(Account)
    case changeKey(Account)

    var id: String {
        switch self {
        case .add: "add"
        case let .reauthenticate(a): "reauth-\(a.id.rawValue)"
        case let .changeKey(a): "key-\(a.id.rawValue)"
        }

    var existing: Account? {
        switch self {
        case .add: nil
        case let .reauthenticate(a), let .changeKey(a): a

@MainActor
final class AddAccountModel: ObservableObject {
    enum Phase: Equatable {
        case editing
        case waitingForBrowser
        case working
        case failed(String)
        case done(String)
    }

    @Published var preset: ServicePreset = .lastfm
    @Published var serverURL = ""
    @Published var keyMode: KeyMode = BuiltInLastFmKey.current == nil ? .own : .builtIn
    @Published var apiKey = ""
    @Published var apiSecret = ""
    @Published var token = ""
    @Published var username = ""
    @Published var password = ""
    @Published var usePassword = false
    @Published private(set) var phase: Phase = .editing

    let mode: AddAccountMode
    private let appModel: AppModel
    private var task: Task<Void, Never>?

    init(mode: AddAccountMode, appModel: AppModel) {
        self.mode = mode
        self.appModel = appModel
        if let account = mode.existing {
            preset = account.preset
            serverURL = account.apiURL.absoluteString
            keyMode = { if case .changeKey = mode { return .own } else { return account.keyMode } }()
            username = account.username
        }
    }

    var builtInKeyAvailable: Bool { preset == .lastfm && BuiltInLastFmKey.current != nil }
    var needsServerURL: Bool { preset == .customAudioscrobbler || preset == .customListenBrainz }
    var supportsWebAuth: Bool { preset.defaultWebAuthURL != nil }

    private var apiURL: URL? {
        needsServerURL ? URL(string: serverURL.trimmingCharacters(in: .whitespaces)) : preset.defaultAPIURL
    }

    private var credentials: (key: String, secret: String)? {
        if keyMode == .builtIn, builtInKeyAvailable { return BuiltInLastFmKey.current }
        let key = apiKey.trimmingCharacters(in: .whitespaces), secret = apiSecret.trimmingCharacters(in: .whitespaces)
        return key.isEmpty || secret.isEmpty ? nil : (key, secret)
    }

    func cancel() {
        task?.cancel()
        task = nil
        phase = .editing
    }

    func signInWithBrowser() {
        guard let apiURL, let credentials, let webAuth = preset.defaultWebAuthURL else {
            phase = .failed(String(localized: "Fill in the server and API key first."))
            return
        }
        let auth = AudioscrobblerAuth(apiURL: apiURL, apiKey: credentials.key, apiSecret: credentials.secret,
                                      transport: appModel.transport)
        task = Task {
            do {
                phase = .working
                let token = try await auth.getToken()
                NSWorkspace.shared.open(auth.authorizationURL(webAuthURL: webAuth, token: token))
                phase = .waitingForBrowser
                let deadline = Date().addingTimeInterval(300)
                while Date() < deadline {
                    try await Task.sleep(nanoseconds: 3_000_000_000)
                    do {
                        let session = try await auth.getSession(token: token)
                        try finish(audioscrobbler: session, apiURL: apiURL, credentials: credentials)
                        return
                    } catch AudioscrobblerAuthError.notAuthorizedYet {
                        continue
                    }
                }
                phase = .failed(String(localized: "Sign-in timed out. Approve access in the browser within 5 minutes, then try again."))
            } catch is CancellationError {
                phase = .editing
            } catch {
                phase = .failed(Self.message(for: error))
            }
        }
    }

    func signInWithPassword() {
        guard let apiURL, let credentials else {
            phase = .failed(String(localized: "Fill in the server and API key first."))
            return
        }
        let auth = AudioscrobblerAuth(apiURL: apiURL, apiKey: credentials.key, apiSecret: credentials.secret,
                                      transport: appModel.transport)
        let (user, pass) = (username, password)
        task = Task {
            phase = .working
            do {
                let session = try await auth.getMobileSession(username: user, password: pass)
                try finish(audioscrobbler: session, apiURL: apiURL, credentials: credentials)
            } catch {
                phase = .failed(Self.message(for: error))
            }
            password = ""
        }
    }

    func connectListenBrainz() {
        guard let apiURL else {
            phase = .failed(String(localized: "Enter the server address."))
            return
        }
        let value = token.trimmingCharacters(in: .whitespacesAndNewlines)
        task = Task {
            phase = .working
            do {
                let name = try await ListenBrainzClient.validate(apiURL: apiURL, token: value, transport: appModel.transport)
                let account = makeAccount(apiURL: apiURL, username: name, keyMode: .own)
                try appModel.accountStore.setSecret(value, .token, for: account.id)
                appModel.accountSignedIn(account)
                phase = .done(String(localized: "Signed in as \(name)"))
            } catch {
                phase = .failed(Self.message(for: error))
            }
        }
    }

    private func finish(audioscrobbler session: AudioscrobblerSession, apiURL: URL,
                        credentials: (key: String, secret: String)) throws {
        let mode: KeyMode = keyMode == .builtIn && builtInKeyAvailable ? .builtIn : .own
        let account = makeAccount(apiURL: apiURL, username: session.username, keyMode: mode)
        let store = appModel.accountStore
        try store.setSecret(session.sessionKey, .sessionKey, for: account.id)
        try store.setSecret(mode == .own ? credentials.key : nil, .apiKey, for: account.id)
        try store.setSecret(mode == .own ? credentials.secret : nil, .apiSecret, for: account.id)
        appModel.accountSignedIn(account)
        phase = .done(String(localized: "Signed in as \(session.username)"))
    }

    private func makeAccount(apiURL: URL, username: String, keyMode: KeyMode) -> Account {
        Account(id: mode.existing?.id ?? .new(), preset: preset, username: username, apiURL: apiURL,
                webAuthURL: preset.defaultWebAuthURL, keyMode: keyMode, addedAt: mode.existing?.addedAt ?? Date())
    }

    static func message(for error: Error) -> String {
        switch error {
        case AudioscrobblerAuthError.tokenExpired:
            return String(localized: "The sign-in link expired. Try again.")
        case let AudioscrobblerAuthError.invalidCredentials(message):
            return message
        case let AudioscrobblerAuthError.failed(inner):
            return message(for: inner)
        case ScrobbleError.signedOut:
            return String(localized: "That token or session isn't valid.")
        case let ScrobbleError.keyUnusable(code):
            return String(localized: "The API key was rejected (error \(code)). Last.fm may require Pro for this key; use your own key.")
        case let ScrobbleError.permanent(message), let ScrobbleError.transient(message):
            return message
        case ScrobbleError.rateLimited:
            return String(localized: "The server is rate limiting requests. Try again in a minute.")
        default:
            return error.localizedDescription
        }
    }
}

            .store(in: &cancellables)

    private func handle(_ snapshot: Snapshot) {

            lastNotifiedTag = playing.tag.key

            content.title = playing.tag.track.title

            content.categoryIdentifier = Self.category
            content.userInfo = ["tag": playing.tag.key.rawValue]
            post(content, id: playing.tag.key.rawValue)
        }
        for (id, problem) in snapshot.problems where lastProblems[id] != problem {
            guard let account = model.accounts.first(where: { $0.id == id }) else { continue }
            let content = UNMutableNotificationContent()
            content.title = String(localized: "ShazamScrobbler needs attention")
            content.body = Formatting.problem(ProblemRow(account: account, problem: problem))
            post(content, id: "problem-\(id.rawValue)")
        }
        lastProblems = snapshot.problems
    }

    private func post(_ content: UNMutableNotificationContent, id: String) {
        UNUserNotificationCenter.current().add(UNNotificationRequest(identifier: id, content: content, trigger: nil))
    }

        let raw = response.notification.request.content.userInfo["tag"] as? String
        if action == Self.dontScrobble, let raw {
            Task { @MainActor in self.model.setChoice(.exclude, for: TagKey(rawValue: raw)) }

#!/usr/bin/env bash
# Enforces the trust boundaries documented in SECURITY.md (spec §13).
set -euo pipefail
cd "$(dirname "$0")/.."
fail=0

# 1. Only ShazamLibrary may reference Shazam's container.
if grep -rnE '4GWDBCF5A4|Group Containers|com\.shazam\.mac' --include='*.swift' Kit/Sources App/Sources \
    | grep -v '^Kit/Sources/ShazamLibrary/'; then
  echo "error: only Kit/Sources/ShazamLibrary may reference Shazam's container" >&2
  fail=1
fi

# 2. ShazamLibrary must not contain networking code.
if grep -rnE 'URLSession|URLRequest|import Network|NWConnection|CFNetwork|NSURLConnection|socket\(|ScrobbleClients' \
    Kit/Sources/ShazamLibrary; then
  echo "error: Kit/Sources/ShazamLibrary must not use networking" >&2
  fail=1
fi

# 3. ShazamLibrary never writes.
if grep -rnE 'readWriteCreate|SQLITE_OPEN_READWRITE|forWritingTo|createFile|removeItem|O_RDWR|O_WRONLY' \
    Kit/Sources/ShazamLibrary; then
  echo "error: Kit/Sources/ShazamLibrary must not write files" >&2
  fail=1
fi

# 4. ShazamLibrary's dependencies stay exactly these.
deps=$(swift package --package-path Kit dump-package | python3 -I -c '
import json, sys
target = next(t for t in json.load(sys.stdin)["targets"] if t["name"] == "ShazamLibrary")
print(" ".join(sorted(d["byName"][0] for d in target["dependencies"])))')
if [ "$deps" != "SQLiteLite ScrobbleCore" ]; then
  echo "error: ShazamLibrary dependencies changed: $deps" >&2
  fail=1
fi

exit "$fail"
```

#!/usr/bin/env bash
# Creates the stable self-signed release identity "ShazamScrobbler Signing" (20 years).
# Full Disk Access and Keychain access follow this identity across updates (spec §6.5, §11):
# losing the private key means every user redoes the Full Disk Access setup once.
set -euo pipefail
cd "$(dirname "$0")/.."
out=signing
mkdir -p "$out"
[ -e "$out/ShazamScrobbler-Signing.p12" ] && { echo "refusing to overwrite $out/ShazamScrobbler-Signing.p12" >&2; exit 1; }

cat > "$out/req.cnf" <<'EOF'
[req]
distinguished_name=dn
x509_extensions=ext
prompt=no
[dn]
CN=ShazamScrobbler Signing
[ext]
basicConstraints=critical,CA:false
keyUsage=critical,digitalSignature
extendedKeyUsage=critical,codeSigning
EOF

openssl req -x509 -newkey rsa:3072 -nodes -days 7300 -config "$out/req.cnf" \
  -keyout "$out/key.pem" -out "$out/cert.pem"
read -r -s -p "Password for the .p12 export: " password; echo
openssl pkcs12 -export -legacy -inkey "$out/key.pem" -in "$out/cert.pem" \
  -name "ShazamScrobbler Signing" -out "$out/ShazamScrobbler-Signing.p12" -passout "pass:$password"
rm "$out/key.pem"

security import "$out/ShazamScrobbler-Signing.p12" -k "$HOME/Library/Keychains/login.keychain-db" \
  -P "$password" -T /usr/bin/codesign
sha1=$(openssl x509 -in "$out/cert.pem" -noout -fingerprint -sha1 | sed 's/.*=//; s/://g' | tr 'A-F' 'a-f')
printf 'identifier "ShazamScrobbler" and certificate leaf = H"%s"\n' "$sha1" > scripts/expected-requirement.txt

cat <<EOF
Done. Next (owner only):
  1. GitHub secret SIGNING_P12_BASE64  = output of: base64 -i $out/ShazamScrobbler-Signing.p12
  2. GitHub secret SIGNING_P12_PASSWORD = the password you just typed
  3. Back up $out/ShazamScrobbler-Signing.p12 + password offline (password manager).
  4. Commit scripts/expected-requirement.txt (public; it pins the release identity).

# Security and privacy

ShazamScrobbler needs **Full Disk Access** because macOS only lets apps read Shazam's history that way. macOS can't limit Full Disk Access to one folder, so here is exactly what the app does with it and how you can check.

## What it reads

One file, read-only:
`~/Library/Group Containers/4GWDBCF5A4.group.com.shazam/com.shazam.mac.Shazam/ShazamDataModel.sqlite`
(plus SQLite's companion `-wal`/`-shm` files, which SQLite reads alongside it).

Only the code in `Kit/Sources/ShazamLibrary/` touches that path. That module contains no networking code and opens the database with `SQLITE_OPEN_READONLY`. CI enforces both rules (`scripts/check-boundaries.sh`) on every change.

It also writes its own state to `~/Library/Application Support/ShazamScrobbler/` and keeps sign-in secrets in your login Keychain.

## What it sends, and where

Only to the accounts you add (Last.fm, Libre.fm, ListenBrainz, or servers you enter) and to GitHub to check for updates. No analytics, no other servers. What's sent: artist, title, album and time of each Shazam tag.

## Verify it yourself

- **This download was built from this repository:** `gh attestation verify ShazamScrobbler-<version>.dmg -R ShazamScrobbler/macos-app` (GitHub build provenance, signed through Sigstore).
- **Checksum:** compare `shasum -a 256 ShazamScrobbler-<version>.dmg` with `SHA256SUMS.txt` on the release.
- **Signing identity:** `codesign -d -r- /Applications/ShazamScrobbler.app` must print the requirement in `scripts/expected-requirement.txt`.
- **Files it opens:** `sudo fs_usage -w -f filesys ShazamScrobbler | grep -v "Application Support/ShazamScrobbler"` — you should only see Shazam's database files.
- **Network:** with [LuLu](https://objective-see.org/products/lulu.html) or Little Snitch, connections go only to your accounts' servers and `github.com` / `objects.githubusercontent.com` (updates).
- **Build it yourself:** see README › Build from source, then give your own build Full Disk Access.

## Reporting a vulnerability

Open a private security advisory on GitHub (Security › Report a vulnerability).
